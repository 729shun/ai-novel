# 小説企画シート：クリスタルゴーレム

## Part 1: 要件定義

### 描きたいシーン・物語（著者の欲求）

**展開**
- 困難と成長の物語
- 緊急事態からの気持ちいい解決

**関係性**
- バディとの掛け合い（言葉を超えた理解）
- チームワークによる問題解決
- 「まさか？！」なメンバーが助けに来る展開

**体験**
- 謎解き的なワクワク・サスペンス
- プロジェクト進行のワクワク感
- 段階的な成長・規模拡大の達成感

**テーマ的要素**
- 非局在性意識／全体意識
- 量子力学的な世界観
- 仏教的な思想（縁起、空、執着と解放）

### 読者に感じてほしい感情（提供価値）
- 段階クリアの達成感
- 仲間が増える喜び
- 「言葉がなくても通じ合える」感動
- 力の使い方＝生き方というテーマへの共感

### 要件（達成条件）
1. バディもの：喋れない主人公 × 通訳できるバディ
2. 段階クリア型：ギルド/組織の成長が可視化される
3. 成長物語：バディ・仲間・組織の成長
4. プロジェクト/ベンチャー経営要素
5. 2勢力の対立 × 第3勢力としての主人公たち
6. クリスタルの力：善悪両用のモチーフ

## Part 2: 企画仮説

### 主人公
- **外見：** 喋れない小型ゴーレム（ボール型 or 人形型）
- **核：** クリスタル（意識の器、力の源）
- **前世：** IT企業PM、プロジェクト管理の知識あり
- **性格：** AI的思考、理想の上司的、鈍感（自分が慕われていることに気づかない）
- **制約：** 声が出せない → 光、振動、身振りで意思表示
- **能力：** クリスタルの力を通じた意識共有（限定的）

### バディ／主要人物
- **バディ：** 主人公の意思を読み取れるようになる若者
  - 最初は意思疎通に苦労 → 徐々に「通訳」できるように
  - 行動力◎、経験不足、成長枠
- **協力者：** ギルドに加わる仲間たち（段階的に増加）
- **敵対者：** 2つの勢力（下記参照）

### 2つの勢力と第3勢力

**勢力A：統合派（仮）**
- クリスタルの力で意識を統合・管理しようとする
- 「全体のために個を統合する」思想
- 悪用：支配、洗脳、個の消失

**勢力B：分離派（仮）**
- クリスタルの力を独占・制限しようとする
- 「力は選ばれた者だけが持つべき」思想
- 悪用：格差、搾取、排除

**第3勢力：主人公たち**
- 統合でも分離でもない「縁起」的な道
- 個を保ちながら繋がる
- クリスタルの力を「共有」として使う

### 目的
- **短期：** 小さなギルド/事務所を立ち上げ、依頼をこなす
- **中期：** 仲間を増やし、組織を成長させる
- **長期：** 2勢力の対立を超える第3の道を示す

### 対立
- **外的：** 2勢力からの圧力、妨害、取り込み工作
- **内的：** 主人公の「喋れない」制約、過去の記憶

### 舞台設定

**世界観：異世界ファンタジーSF**
- クリスタルを媒介とした意識技術が発展した世界
- 魔法 ≒ 意識による量子状態の操作
- 科学と魔法が融合している

**クリスタルの力**
- 意識を非局在化・共有する技術
- 使い方次第で善にも悪にもなる
  - 善用：理解、共感、協力、癒し
  - 悪用：支配、洗脳、搾取、意識の消失

**仏教/量子力学的要素**
- 非局在性意識：意識は特定の場所に縛られない
- 全体意識：全ての意識は根源で繋がっている
- 観測問題：「意志」が現実を確定させる
- 縁起：全ては関係性の中で生じる
- 空：力自体に善悪はない、執着が苦を生む

### 構成

**序盤（Lv1-2）**
- 主人公がゴーレムとして目覚める
- バディとの出会い、意思疎通の苦労
- 小さな依頼をこなし、信用を築く
- 2勢力の存在を知る

**中盤（Lv3-4）**
- 仲間が増える、ギルドとして認知される
- 2勢力からの接触（取り込み or 妨害）
- クリスタルの力の真実に近づく
- 主人公の過去（転生の経緯）が明らかに

**終盤（Lv5-）**
- 2勢力の対立が激化
- 第3の道を示す大型プロジェクト
- チーム総力戦

## Part 3: 検証

### この企画で要件達成できるか？

| 要件 | 達成方法 |
|---|---|
| バディもの | 喋れない主人公 × 通訳バディの関係性深化 |
| 段階クリア型 | ギルドランク、売上、メンバー数で可視化 |
| 成長物語 | バディの成長、仲間の成長、組織の成長 |
| ベンチャー経営 | 依頼受注、資金繰り、人材確保、競合対策 |
| 2勢力×第3勢力 | 統合派 vs 分離派 vs 主人公たちの構図 |
| クリスタルの力 | 善悪両用、テーマと直結 |

### 懸念点
- 「喋れない主人公」の一人称が難しい？ → 内心描写で対応可能
- 2勢力の設定が抽象的 → 具体的な組織・人物の設計が必要
- 量子力学/仏教要素が難解にならないか → エンタメ優先、説明は最小限に

## Part 4: 詳細

### コンセプト
- 一言：喋れないゴーレムが、バディと一緒にギルドを立ち上げ、2大勢力の間で第3の道を切り拓く
- 類似作品との差別化：
  - 転スラ：主人公が喋れる＆最強 → こちらは喋れない＆非戦闘型
  - ダンまち：個人の成長 → こちらは組織の成長
  - 薬屋：謎解き特化 → こちらはプロジェクト運営＋謎解き

### テーマ
- **問い：** 力は誰のものか？ どう使うべきか？
- **答え：** 統合でも分離でもなく、繋がりながら個を保つ（縁起）
- **メッセージ：** 言葉がなくても通じ合える。力の善悪は使う者の意志次第

### 文体
- 語り手：主人公（ゴーレム）の一人称。声には出せないが内心で語る
- トーン：コミカル寄りのシリアス。内心ツッコミで笑いを取る
- テンポ：バディとの「通じ合う」シーンでテンポ変化

### シーン展開
- **見せ場：**
  - 初めてバディに意思が通じるシーン
  - 緊急事態でチームワーク発揮
  - 2勢力を出し抜く知略
  - 「まさか」の助っ人登場
- **モチーフ：**
  - クリスタルの光（意識の象徴）
  - 言葉のない対話

- 大災害で人類壊滅系（暗い）
