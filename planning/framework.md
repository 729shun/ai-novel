# 小説企画シート：ペットロボ転生

## Part 1: 要件定義

### 描きたいシーン・物語（著者の欲求）

**展開**
- 困難と成長の物語
- 緊急事態からの気持ちいい解決

**関係性**
- バディとの掛け合い（言葉を超えた理解）
- チームワークによる問題解決
- 「まさか？！」なメンバーが助けに来る展開

**体験**
- 謎解き的なワクワク・サスペンス
- プロジェクト進行のワクワク感
- 段階的な成長・規模拡大の達成感

**コメディ要素**
- ジェスチャー誤訳からの結果オーライ
- 内心毒舌ツッコミ（読者だけが知っている）
- 見た目と中身のギャップ

**テーマ的要素**
- 非局在性意識／全体意識
- 量子力学的な世界観
- 仏教的な思想（縁起、空、執着と解放）

### 読者に感じてほしい感情（提供価値）
- 段階クリアの達成感
- 仲間が増える喜び
- 「言葉がなくても通じ合える」感動
- コメディとしての笑い
- 力の使い方＝生き方というテーマへの共感

### 要件（達成条件）
1. バディもの：喋れない主人公 × 誤訳するバディ
2. 段階クリア型：ギルド/組織の成長が可視化される
3. 成長物語：バディ・仲間・組織の成長
4. プロジェクト/ベンチャー経営要素
5. 2勢力の対立 × 第3勢力としての主人公たち
6. クリスタルの力：善悪両用のモチーフ
7. コメディ：誤訳→結果オーライの笑い

## Part 2: 企画仮説

### コンセプト（1行）

> **転生したら戦闘支援ができるボール型ペットロボでした**
> ——喋れないので、信じて任せます

### 主人公
- **外見：** ハロ的なボール型サポートロボ（可愛い）
- **役割：** 戦闘支援（分析、索敵、警告、ナビ）
- **核：** クリスタル（意識の器、力の源）
- **前世：** IT企業PM、プロジェクト管理の知識あり
- **性格：** 内心は毒舌・ツッコミ体質・段取り厨。でも表に出せない
- **制約：** 声が出せない → 光、振動、身振りで意思表示
- **能力：** 戦闘支援 + クリスタルの力を通じた意識共有（限定的）

**ギャップ構造：**
```
見た目：可愛いサポートロボ（ハロ的）
役割：戦闘支援（本来は脇役ポジ）
中身：おっさんPM（内心毒舌）
立場：なぜかリーダーに（主役ポジ）
```

### バディ：ユナ
- 主人公を「可愛い〜」と拾った少女
- 主人公の意思を「なんとなく」読める唯一の存在
- **ただし誤訳率50%**
- 行動力◎、経験不足、成長枠
- 両親を「統合」で失い、教会を憎んでいる

**掛け合いの型：**
```
主人公：（逃げろって言ってる！）→ ピカピカ
ユナ：「え、『行け』ってこと？」→ 突撃
結果：なぜか成功
主人公：（……まあいいか）
```

### 仲間（段階的に増加）
- **カイル（元・統合派の神官）** — 組織に疑問を持って脱走。生真面目すぎて空回り
- **リオ（元・分離派の調査員）** — 冷静沈着だがコミュ障。ユナとの会話が噛み合わない

### 2つの勢力と第3勢力

**勢力A：統合派（クリスタル教会）**
- クリスタルの力で意識を統合・管理しようとする
- 「全体のために個を統合する」思想
- 悪用：支配、洗脳、個の消失
- リーダー：大司教ヴェルナ（50代女性）— 穏やかな微笑みの裏に狂信

**勢力B：分離派（クリスタル商会）**
- クリスタルの力を独占・制限しようとする
- 「力は選ばれた者だけが持つべき」思想
- 悪用：格差、搾取、排除
- リーダー：総裁ドレイク（60代男性）— 冷徹な実業家

**第3勢力：主人公たちのギルド**
- 統合でも分離でもない「縁起」的な道
- 個を保ちながら繋がる
- クリスタルの力を「共有」として使う

### 目的
- **短期：** 小さなギルド/事務所を立ち上げ、依頼をこなす
- **中期：** 仲間を増やし、組織を成長させる
- **長期：** 2勢力の対立を超える第3の道を示す

### 対立
- **外的：** 2勢力からの圧力、妨害、取り込み工作
- **内的：** 主人公の「喋れない」制約、過去の記憶

### 舞台設定

**世界観：異世界ファンタジーSF**
- クリスタルを媒介とした意識技術が発展した世界
- 魔法 ≒ 意識による量子状態の操作
- 科学と魔法が融合している

**クリスタルの力**
- 意識を非局在化・共有する技術
- 使い方次第で善にも悪にもなる
  - 善用：理解、共感、協力、癒し
  - 悪用：支配、洗脳、搾取、意識の消失

**仏教/量子力学的要素**
- 非局在性意識：意識は特定の場所に縛られない
- 全体意識：全ての意識は根源で繋がっている
- 観測問題：「意志」が現実を確定させる
- 縁起：全ては関係性の中で生じる
- 空：力自体に善悪はない、執着が苦を生む

### 構成

**序盤（Lv1-2）**
- 主人公がペットロボとして目覚める
- ユナに拾われる（「売ろう」→「飼う」）
- 意思疎通の苦労、誤訳コメディ
- 小さな依頼をこなし、信用を築く
- 2勢力の存在を知る

**中盤（Lv3-4）**
- 仲間が増える（カイル、リオ）
- 全員が主人公のジェスチャーを違う意味に解釈
- 2勢力からの接触（取り込み or 妨害）
- クリスタルの力の真実に近づく
- 主人公の過去（転生の経緯）が明らかに

**終盤（Lv5-）**
- 主人公が「両勢力の創設者」だったことが判明
- 2勢力の対立が激化
- 第3の道を示す大型プロジェクト
- チーム総力戦

## Part 3: 検証

### この企画で要件達成できるか？

| 要件 | 達成方法 |
|---|---|
| バディもの | 喋れない主人公 × 誤訳バディの関係性深化 |
| 段階クリア型 | ギルドランク、売上、メンバー数で可視化 |
| 成長物語 | バディの成長、仲間の成長、組織の成長 |
| ベンチャー経営 | 依頼受注、資金繰り、人材確保、競合対策 |
| 2勢力×第3勢力 | 統合派 vs 分離派 vs 主人公たちの構図 |
| クリスタルの力 | 善悪両用、テーマと直結 |
| コメディ | 誤訳→結果オーライの笑い、内心ツッコミ |

### 「面白そう」ポイント

| 要素 | 効果 |
|---|---|
| ジェスチャー誤訳コメディ | 笑える、絵が浮かぶ |
| 内心毒舌ツッコミ | 読者だけが知ってる優越感 |
| 結果オーライ | スカッとする |
| 訳ありメンバー | 群像劇の種 |
| 「両勢力の創設者」 | 後半のシリアス展開への布石 |

### 懸念点
- 「喋れない主人公」の一人称が難しい？ → 内心描写で対応可能
- 2勢力の設定が抽象的 → 具体的なエピソードで見せる
- 量子力学/仏教要素が難解にならないか → エンタメ優先、説明は最小限に

## Part 4: 詳細

### テーマ
- **問い：** 力は誰のものか？ どう使うべきか？
- **答え：** 統合でも分離でもなく、繋がりながら個を保つ（縁起）
- **メッセージ：** 言葉がなくても通じ合える。力の善悪は使う者の意志次第

### 文体
- 語り手：主人公（ペットロボ）の一人称。声には出せないが内心で語る
- トーン：コミカル寄りのシリアス。内心ツッコミで笑いを取る
- テンポ：誤訳→結果オーライのリズム

### シーン展開
- **見せ場：**
  - 初めてユナに意思が通じるシーン
  - 誤訳からの予想外の成功
  - 緊急事態でチームワーク発揮
  - 2勢力を出し抜く知略
  - 「まさか」の助っ人登場
- **モチーフ：**
  - クリスタルの光（意識の象徴）
  - 言葉のない対話
