## 1. 村は何のためにあるか

**星降りを受け止め、石積みを守り、受け手を育てる**ための場所。三つが一体。

- 星降りを受けた**熾石**が村の熱と収入（`衝突.md` §2）
- 受け止め続けた場所だけが、底なしにならずに残っている（`村の外.md` §1）。**受け止めをやめれば、村の足元が穴になる**
- 受け手は**眠りの器が大きい子**から選ばれる。寝つきがよく、長く眠れる子（`石.md` §4）。受け手は敬われるが、自由はない

## 2. 掟（第一部に出るものだけ）

| 掟 | 村の理屈（村人が本気で信じている理由） |
|---|---|
| 村から出てはならない | 外は底なし。順路を知らずに出た者は落ちる。**掟の半分は本当に命を守っている** |
| 順路は口外してはならない | 順路を知る者が勝手に出入りすれば、村が外に見つかり、奪われる（飛空艇の者たちへの警戒も少し入っている） |
| 石積みに触れてよいのは受け手と祈る者だけ | 石積みは先代たちの眠り。乱すことは先代を起こすこと（＝崩すこと） |
| 受け手は役目を降りてはならない | 降りれば星降りを受けられず、村が穴になる |
| 雪を払い、祈りを欠かさない | 石積みが埋もれると力が弱まる（＝実際に太郎の意識が薄れる。信心の形をした、正しい保守作業） |
| 受け手の眠りを妨げてはならない | 眠りは借りを返す時間。受け手が寝ている間は村じゅうが静かにする（コミカルにも厳粛にも使える） |

**村の繰り返しには、ちゃんと意味がある。** 敵は村人ではなく「意味があるから変えられない」こと（前回から変わらず）。

## 3. 掟を破った者の扱い：追放（作者決定）

詳細は `村の外.md` §4。第一部に効くところだけ：

- 追放は「次の飛空艇に引き渡す」か「順路を教えずに外へ出す」
- 月の子の年は飛空艇が間に合わないので、**花子は順路なしで出される**（＝事実上の死）か、月の子が過ぎるまで閉じこめられる
- 根石（太郎）は取り戻され、石積みの一番下に戻される → **太郎は戻されれば潰れる**（`石積み.md` §3）
- 花子は外へ、太郎は石積みの下へ。**二人が引き離されることが、そのまま二人ともの終わり**になる

（前回案の「盗人を受け手の代わりにする」は不採用。ただし「花子のほうが石積みとよく響く」と村が気づく要素は、キャラ担当の村長格「一人を差し出す」と組み合わせて残せる。採るかはプロット担当・作者次第）

## 4. 各地に村と石積みがある

- 輪のかけらが落ちる**帯**に沿って、村が点々と並ぶ（`衝突.md` 案B）
- 村どうしは行き来しない。地上は底なしで、順路は村ごとの秘密。知っているのは、飛空艇の者たちが他の村にも寄っていることだけ（「東の村は今年、熾石が少なかったそうだ」と乗員が漏らす）
- 月の子は、**帯のどこかに**落ちる。どの村に落ちるかは年によって違う。今回はこの村の番、と言い伝えと星降りの重さでわかる
- **月の子を受けそこねて消えた村**の跡は、底なしの大穴として残っている（地下世界の入口のひとつ）

### 後の「石を集める旅」へ

| 第一部で置く種 | 後半での芽 |
|---|---|
| 飛空艇の乗員が漏らす他の村の話 | 他の村、他の石積み、他の受け手（同じ力を持つ者どうしの戦い） |
| 消えた村の大穴 | 持ち主のない石積み、埋もれた石の発掘 |
| 花子の夢の「迎えに行けば逸らせた」 | 石の力を重ねて月の子を押す（旅の目的） |
| 根石には誰かがいる | 他の村の根石にも誰かがいるのか（太郎の同類＝仲間） |

## 5. 村の暮らしの小道具

- 祠の石積み（毎朝の雪かき）
- 星降りの月：一年で一番忙しく、一番危ない月。終わると受け手が冬寝に入る
- 熾石の蔵。飛空艇が来る日の取引
- 暦：「◯つ目の石の、◯年目」
- 道守が杖で雪を叩いて歩く音（毎年の順路づくり）
