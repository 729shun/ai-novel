## 1. 村は何のためにあるか

**受け止め役を育て、石を守り、石の熱を分けて冬を越す**ための仕組み。三つが一体になっている。

- 石の熱は村の人数ぶんしかない（メモ「江戸時代のような閉鎖的な環境、人口維持」）
- 受け手は、生まれた時から決まっている（または幼いうちに選ばれる）。毎朝石に触れ、作法を覚え、石と体を慣らしていく
- 村人はみな、受け手のおかげで冬を越せると知っている。受け手は**敬われるが、自由はない**

## 2. 掟（第一部に出るものだけ）

| 掟 | 村の理屈（村人が本気で信じている理由） |
|---|---|
| 村から出てはならない | 外には石の熱がない。出た者はたいてい凍えて死ぬ。**掟の半分は本当に命を守っている** |
| 石に触れてよいのは受け手と祈る者だけ | 石の熱は村の財産。勝手に引き出すのは、皆の冬を盗むこと |
| 受け手は役目を降りてはならない | 降りれば次の巡りが来ない（＝村が滅ぶ）。替わりは育っていない |
| 雪を払い、祈りを欠かさない | 石様が眠ってしまう（＝実際に太郎が眠る。信心の形をした、正しい保守作業） |

最後の掟がポイント。**村の繰り返しには、ちゃんと意味がある。** だから村を悪者にせずに「繰り返し」を敵にできる。敵は村人ではなく、「意味があるから変えられない」こと。

## 3. 掟を破った者の扱い

### 案Cを選ぶと起きること

花子が捕まったあと、村の年寄りは気づく：**この女は、大志より石とよく響く。**（花子は前回の受け手とつながっているので。`花子の記憶.md`）
「罰」と「都合」が一致してしまい、村は花子を受け手にしようとする。

- 花子：罰として、自分が壊したかった繰り返しの一部にされる
- 大志：役目を、結局盗まれる。しかも村そのものに
- 太郎：花子が受け手になっても、自分は上書きされる。しかも花子も失う

三人とも「このままだと困る」状況に、偶然ではなく**村の掟と石の仕組みから**追い込まれる。山場で誰かが選ぶ理由が強くなる。
※ 誰が何を選ぶかはキャラクター側で。ここでは「選ばざるを得ない状況」まで。

## 4. 各地に村と石がある

- 巡ってくるものは近づくと割れ、かけらが各地に落ちる。**どの村も同じ夜に、それぞれの石で受け止める**
- 村どうしは行き来しない（外は凍える。掟もある）。互いのことは「東の鐘」「北の鐘」くらいにしか知らない
  → 衝突が近づいて石が鳴るとき、**遠くの石の鳴りがかすかに聞こえる**。他の村があることを、太郎は音で知る
- 第一部で見せるのはここまで

### 後の「石を集める旅」につながるか → つながる

| 第一部で置く種 | 後半での芽 |
|---|---|
| 遠くの鐘の音 | 他の村、他の石、他の受け手（同じ力を持つ者どうしの戦い） |
| 「受け手を出せなかった村は滅んだ」という昔話 | 滅んだ村の跡に、持ち主のない石が埋まっている（発掘、レア物） |
| 花子の記憶の「音がそろっていなかった」 | 石を集めて鳴りをそろえれば、衝突を逸らせるかもしれない（旅の目的） |
| 石には先代がいる | 集めた石それぞれに人格がいる。太郎の同類＝仲間が増える |

## 5. 村の暮らしの小道具（場面に必要になったら使う程度）

- 石の祠（雪に埋もれやすい場所。毎朝の雪かき）
- 受け場と、像の並ぶ道（`衝突.md` 案Bの部品。採るなら）
- 熱の配り：夜ごと、受け手か年寄りが石の熱を炉に分ける儀式。巡りの終わりなので**炉の火が年々小さい**
- 暦：「巡り何年目」
