# 村の外：底なし・正しい順路・配給の飛空艇・地下世界

> AIの検討。決めるのは作者。作者の決定は `設計/決定ログ.md`（2026-11-18：掟を破った者は追放。村の周りは底なしで、出口は定期配給の飛空艇か正しい順路だけ。それ以外は地下世界へ落ちる）。
> 第一部では「見せる」のは底なしと順路と飛空艇まで。地下世界はにおわせ（第一部の終わりで落ちるかどうかはプロット担当次第）。

---

## 1. 底なしの成り立ち（`衝突.md` 案Bの場合）

- 村は、輪のかけらが落ちる**帯**の上にある。何千年も星降りを受けてきた土地
- この土地は、厚い**氷床**（凍土と氷が何百mも重なったもの）の上にある
- 受け止めそこねた星降りのかけらは、熱い塊のまま氷を溶かしながら沈み、**深い竪穴**を開ける。穴の中で溶けた水は流れ去り、下には**空洞**が残る
- 何千年も続いたので、村のまわりの氷床は**蟻の巣のように空洞だらけ**。上には雪が積もって、**雪の橋（スノーブリッジ）**で穴がふさがっている
- 見た目はただの雪原。でも**ほとんどの場所は、薄い雪の下が底なし**
- 村だけが落ちないのは、**石積みが星降りを受け止めてきたから**。受け止めた場所には穴が開かない。村は、**受け止め続けた分だけ残った固い島**

→ 村がなぜ出られないか、なぜ受け止めをやめられないか、が地形そのものになる。受け止めをやめれば、村の足元も穴になる。

## 2. 正しい順路

- 空洞と空洞のあいだに残った**固い氷の尾根**をつないだ道。雪の上からは見分けがつかない
- **毎年変わる。** 星降りが新しい穴をあけ、古い尾根が崩れるから。星降りの月が終わるたびに、村の「道守（みちもり）」が杖で叩いて歩き、新しい順路を覚え直す
  - 順路そのものが**繰り返しの仕事**。覚えても毎年作り直し
- 順路は**口伝え**で、書かれていない。知っているのは道守と長だけ（誰が道守かはキャラ担当次第。老人が適役かも）
- **花子は順路を知っている**——ただし**前回の受け手の夢で見た、何百年も前の順路**。今は崩れている場所がある（トラブルに巻き込む偶然として使える。助ける偶然ではない）

## 3. 配給の飛空艇

| 項目 | 内容 |
|---|---|
| 来る時期 | 年に一度、**星降りの月が終わったあと**。村の熾石（受け止めたかけら）を引き取りに来る |
| 運んでくるもの | 塩、薬、布、刃物、種。村では作れないもの |
| 持っていくもの | 熾石。**それと、村が差し出すもの**（追放者、など。下記） |
| 誰が出しているか（におわせ） | 第一部では正体を出さない。におわせる手がかりだけ：<br>・乗員は**雪の上に降りない**（はしごの先で取引する）<br>・船腹に、村人には読めない古い紋<br>・乗員の言葉が少し違う。「下の人」と村人を呼ぶ<br>・熾石の量を量って帳面につける。足りない年は取引が渋い |
| 後半での正体の候補（倉庫） | 旧案の**軌道エレベーター／軌道上の人々**。熾石を集めて自分たちの暮らしに使っている。村の繰り返しは、上の者にとって都合のいい**畑** |

## 4. 追放

- 掟を破った者は、**次の飛空艇に乗せられる**か、**順路を教えずに村の外へ出される**
  - 飛空艇：乗員に引き渡す。どこへ連れて行かれるか、村人は知らない（上の労働力にされる、という噂）
  - 順路なしで出す：事実上、底なしに落ちる。村は手を汚さず、「雪が決めた」と言う
- 月の子の年は飛空艇が来る前に月の子が来るので、**追放は「順路なしで出す」しかない**。または、月の子のあと最初の飛空艇まで、花子を閉じこめておく
- 太郎（根石）は取り戻され、花子だけが出される、というのが村の筋。**花子と太郎が引き離される**危機になる

## 5. 地下世界（落ちた先）

第一部では、においだけ。本格的には第二部から（発掘の舞台）。

| 場所 | 中身 | 構想メモの元 |
|---|---|---|
| 竪穴 | 星降りがあけた深い縦穴。壁に、何千年分の星降りのかけら（熾石）が埋まっている。**掘れば宝の山** | 竪穴に落ちる、立杭 |
| 氷の地下街 | 空洞をつないで暮らす人々。追放された者、落ちた者の子孫。上の村とは別の掟で生きている | 氷の地下街、地下に住み着く人々 |
| 地下の温泉 | 星降りの熱と地熱で、氷の下に湯がわく場所。地下の人々の暮らしの中心 | 地下の温泉 |
| 古い層 | もっと深いところに、輪ができる前の時代のもの（古代の機械、昔の石積み、船） | 備蓄品や兵器が保管されている地下施設、封印、船 |

- 第一部でのにおわせ方：穴から吹き上がる**温かい風**、ときどき聞こえる**人の声のような音**、村の子どもの怖い話（「落ちた者は下で生きている」）
- 「底なし」は村人にとって死の同義語。でも本当は**底がある**。この反転が第二部の入口になる

## 倉庫

| 項目 | 後半でどう効くか |
|---|---|
| 飛空艇の持ち主（軌道上の人々） | 熾石で暮らす上の者。繰り返しが続くと得をする側 |
| 追放者がどこへ行ったか | 上で働かされている／地下で生きている。花子の過去と関わるかもしれない（キャラ次第） |
| 地下の古い層 | 船（旧案の飛空艇）、古代の石、封印。石を集める旅の最初の発掘先 |
| 各地の村をつなぐ地下の道 | 地上は底なしでも、地下でつながっている |
