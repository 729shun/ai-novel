## 0. 物理として外せない一点

**ぶつかったものは戻ってこない。** 「巡ってくる」をほんとっぽくするには、どの案でも次の形にする：

> 大きな**本体**は地球に**かすめるだけ**で、そのたびに**かけらを落として**、また去っていく。
> 本体から出た細かいかけらは、本体の通り道に**帯のように散らばっていて**、地球がそこを通るたびに降る。

現実にも近い例がある：
- **流星群**（ペルセウス座流星群など）：彗星が通り道にばらまいたかけらの帯を、地球が毎年同じ時期に横切る → 毎年同じ季節に降る
- **潮汐破壊**（シューメーカー・レヴィ第9彗星）：大きな天体に近づきすぎた彗星が引きちぎられ、かけらが列になって降った
- **ロッシュ限界**：惑星に近づきすぎた小天体は、潮の力で崩れる。崩れたかけらの一部が落ち、残りは軌道に残る

マスター案「本体は数百年〜千年で戻り、そのあいだ砕けたかけらが毎年『星降り』として降る」は、この形にそのまま乗る。以下の3案は、どれもこの形を守っている。

## 1. 三つの案

### 案A：砕けた彗星の流れ（自然）

| 項目 | 内容 |
|---|---|
| 周期 | **星降り：毎年**（同じ季節）／**本体：数百年ごと** |
| なぜ巡るのか | 大昔に割れた巨大な彗星の残骸が、地球の通り道と交わる軌道を回っている。木星との共鳴で、数百年ごとに一番大きな塊（本体）が地球の近くを通る。現実の「おうし座流星群とその元の天体群」をめぐる仮説（巨大彗星が割れて、何千年も周期的に降らせ続けている）が下敷きにできる |
| 地上で起こること | 毎年冬の一時期が「星降りの月」。降り積もった塵が空を曇らせる。本体の年は火球が何十も落ち、塵が増えて何十年も冬が深まる |
| 弱いところ | 本体が「近づいてかすめる」には、毎回ずいぶん地球に寄らないといけない。少し都合がいい。村が帯状に並ぶ理由が弱い（流星はどこにでも降る） |

### 案B：地球の輪と「月の子」（自然。古い衝突の名残）← おすすめ

| 項目 | 内容 |
|---|---|
| 周期 | **星降り：毎年**（輪のかけらが落ちてくる季節がある）／**本体（月の子）：数百年〜千年ごと** |
| なぜ巡るのか | 大昔の大衝突で、地球のまわりに**土星のような輪**ができた。輪のそばを、大きめの塊（月の子＝小さな衛星）が細長い楕円で回っている。月の引力の影響で、その楕円は**数百年かけて少しずつつぶれていき**、一番近づく年には地球に寄りすぎて、潮の力でかけらがはがれ落ちる。本体の残りはまた遠ざかる。これが「旋回して戻ってくる」（構想メモ） |
| 地上で起こること | **輪が冬の側の半球に影を落とす**ので、冬が長く深い（「一年の大半が冬」の理由になる）。輪の塵で空はいつも白く曇る（「青空しらない」）。曇りの切れ目から、空を横切る白い帯がまれに見える。輪のかけらは**赤道に近い帯**に落ちやすいので、落ちる場所が帯状に決まる → **村が帯に沿って並んでいる**理由になる |
| ほんとっぽさの根拠 | 「4億6600万年前ごろ、地球に一時的に輪があり、その影で寒冷化した」という研究がある（オルドビス紀のクレーターが当時の赤道沿いに並んでいる、という指摘から）。輪の物質は数十万〜数千万年かけて落ちてくるので、**遠い未来の長い時間**と相性がいい |
| 弱いところ | 輪の仕組みを本文で説明しすぎると重い。本文では「空の帯」と「月の子」という呼び名だけで足りる |

### 案C：古代の配達便（人工）

| 項目 | 内容 |
|---|---|
| 周期 | 星降り：毎年／本体：数百年ごと（もとは**決まった日程**で来る便だった） |
| なぜ巡るのか | 大昔の文明が、地球と火星（など）を行き来する**往復軌道（サイクラー軌道。実際に研究されている、燃料なしで二つの惑星のあいだを周期的に回る軌道）**に、氷や資源を積んだ塊を乗せていた。受け取る側の装置が「石」。文明が衰えたあとも便だけが来つづけ、受け取り方を忘れた人々には災厄に見える |
| 地上で起こること | 案A・Bと同じでよい（寒さ・曇りは別の原因が要る） |
| 良いところ | **繰り返しの正体が「誰も目的を覚えていない仕組み」**になる。テーマと一番強く結びつく。旧案の火星・軌道上の人々・「古代文明がわざと」を一本で回収できる |
| 弱いところ | 表に出すと、すぐに謎が解けてしまう。**表の説明には向かない。隠された秘密向き** |

### おすすめ：表はB、底にC

- 村人と読者が見るのは**案B**（輪・月の子・星降り）。寒さ、曇り、雪、村が帯に並ぶこと、が一度に説明できる
- 物語の後半で、**月の子は自然の衛星ではなく、古代の配達便（または旧案の「傘」の残骸）だった**とひっくり返す余地を残す（倉庫）
- 案Aを選んでも、下の「村の暮らし」はほぼ同じ形で使える

## 2. 村から見た衝突（案Bの場合）

### 二種類の「降るもの」

| | 星降り（毎年） | 月の子の降り（数百年に一度） |
|---|---|---|
| 何が降る | 輪のかけら。拳から人の頭くらい | 月の子からはがれた大塊。村ひとつ消える大きさ |
| 誰が受ける | 受け手（大志）が石積みの力を借りて受ける。**毎年の仕事** | 受け手が**すべてを差し出して**受ける。受け手は石になる（`石積み.md`） |
| 受けるとどうなる | かけらがやわらかく落ち、**熾石（おきいし）**として拾える＝村の燃料・熱の源 | 村が助かる。大塊の芯が、受け手の石として石積みに加わる |
| 受けないと | かけらは地面で弾けて穴をあける。燃料にならない | 村が消える。帯に沿ってまた一つ「底なし」が増える |

### なぜ村はその熱やエネルギーに頼るのか

- **熾石**（受け止めた星降りのかけら）が、村の炉・畑・雪解けの熱になる。輪の影で日がほとんど当たらない土地では、空から降ってくるものが**唯一の収穫**
- つまり星降りは**災いであり、刈り入れ**。村の一年は星降りの月を中心に回る（田植唄のかわりの「星降り唄」もありうる）
- 熾石は村の外にも売れる。**配給の飛空艇が熾石を持っていき、塩や薬や布を置いていく**（`村の外.md`）。村は誰かの畑でもある
- 熱は「代償」ではなくなったが、**石の力の一つ**として、また**暮らしの通貨**として残る（決定ログ：熱を力の一種として残すのは可）

### 次はいつか

- 月の子が近づく年は、**数年前から星降りが重く、多くなる**（かけらの密度が上がる）。村の年寄りは石積みの記録と星降りの重さで、「次は月の子の年だ」と知る
- 物語の始まりは、**月の子の年の冬**。今年の星降りの月の最後の夜に、月の子が来る
- 曇り空なので本体は見えない。最後の数夜は雲の上が**白く明るくなり**、夜が来なくなる

### 村の時間感覚

- 年は**石積みの段**で数える。「七つ目の石の、三百十二年目の冬」。石積みがそのまま暦になる
- 人の一生（数十年）は、月の子の周期（数百年）に対して短い。**月の子を二度見る人はいない**。だから「前回」は誰の記憶にもなく、**言い伝えと石積みと、花子の夢**にしか残っていない
- ふだんの繰り返しは**毎年の星降り**（小さな繰り返し）。数百年に一度の月の子は、誰も経験したことのない**大きな繰り返し**。二重の繰り返し
- 一段の重み：石積みが今◯段なら、この村は◯×数百年ここにある。**12段なら約数千年**、30段なら1万年を超える。「壮大さ」はこの数字で出せる（作者に決めてほしいこと）

## 3. 衝突を回避する道（第一部では匂わせるだけ）

`花子の記憶.md` に詳しく。要点：

- 前回の受け手は、最後の瞬間に「**待って受けるんじゃなかった。迎えに行けば、逸らせた**」と感じた
- 月の子は**かすめて去る天体**なので、近づく前に少し押せば、地球に寄らずに通り過ぎる（天体の軌道は、遠くで小さく押すほうが効く。これは物理的にも正しい）
- 「村で待つ」ことが繰り返しで、「迎えに行く」ことが村を出ること。**テーマを台詞にせず、仕組みで言える**
- 後半：迎えに行くには、空へ上がる手段（飛空艇／飛空艇を出している外の者たち）と、ひとつの石積みでは足りない力（**各地の石を集める**）が要る
