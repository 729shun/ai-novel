# 花子が前回の受け手の記憶を見る理由と、回避の手がかり

> AIの検討。決めるのは作者。人物の内面・動機の深さはキャラクター側で。
> ここでは「なぜ見えるか」「何が見えるか」の仕組みだけ。

---

## 1. なぜ花子に見えるのか

前提：受け手は受け止めた瞬間に石へ入るはず（`衝突.md` 案B）。前回は**入れなかった**。

| 案 | 中身 | 効き方 |
|---|---|---|
| **A（おすすめ）：同じ刻に生まれた** | 前回の衝突の夜に生まれた赤ん坊のなかに、行き場を失った受け手の人格の一部が流れ込んだ。花子はそのとき生まれた | 花子の年齢＝巡りの長さ（約23年）になる。「物心ついた時から」が説明不要になる |
| B：受け手の血縁 | 受け手の子・孫なのでつながった | 分かりやすいが、人物関係が強く決まってしまう（キャラクター側の判断に食い込む） |
| C：石に触れた | 幼い頃に何かの理由で石に触れた | 理由づけが別に要る |

### 案Aの細部

- 花子は**この村の生まれではない**（または村の外で生まれた）としても成り立つ。人格は石どうしの鳴りに乗って遠くまで流れた、とすればよい。どこで生まれたかはキャラクター側で
- 花子が見えるのは**「一部」だけ**。受け手そのものではない。花子は花子のまま、他人の無念を自分のことのように感じている（構想メモどおり）

## 2. 何が見えるのか（第一部で使えるかけら）

前回の受け手の、**ふだんの暮らし**と**最後の数瞬**。

### ふだんの暮らしのかけら → 第一部で実用になる

- 村の道、祠の場所、年寄りの若い頃の顔、口癖
- **花子が村に忍び込めるのは、この記憶のおかげ**。初めて来た村なのに道を知っている（偶然ではなく、仕組みから来る「できること」）
- 村人のほうも気味悪がる：「なぜよそ者が、先代様しか知らないことを知っている」→ 捕まったあと、案Cの「受け手の代わり」に話がつながる（`村.md`）

### 最後の数瞬 → 回避の道の匂わせ

第一部で見せるのは、これくらいでよい：

1. 受け場に立つ。雲が赤い。石を胸に当てる
2. 遠くから、**ほかの石の鳴りが聞こえる**。いくつも。でも**音がそろっていない**
3. 一瞬、「受け止めるんじゃない、押せる」と感じる。手を伸ばす
4. 間に合わない。熱が体を通る。**石に入ろうとして、入れない**。ここで途切れる

花子が分かっているのは「何かが違った」「もっとやれたはず」という感覚だけ。**花子もよく分かっていない**（構想メモどおり）ので、太郎と説明でモメる。

## 3. 太郎との関係で起きること

- 花子が石を強く握ると、記憶の鳴りが石に伝わる。**太郎にも一瞬だけ見える**、という手がある
  - 太郎が「回避できたかもしれない」を言葉ではなく体で知る場面になる
  - 太郎にとって、花子の言うことが「信じるしかない話」から「自分も見た話」に変わる瞬間（使うなら第一部の後半）
- 太郎の上書きの話とも絡む：前回の受け手が石に入れなかったから、石が空いていた → 太郎がいる（`石.md` 候補①）。花子は**自分の中にいる人の居場所に、太郎が座っている**と感じるかもしれない。これはモメる理由にも、絆の理由にもなる（どちらにするかはキャラクター側）

## 4. 第一部ではやらないこと

- 回避の方法を具体的に説明しない（「鳴りをそろえる」は後半で言葉になる）
- なぜ前回の受け手が石に入れなかったかの理由（倉庫：太郎がもういたから？＝ `石.md` 候補②と結ぶと、太郎の存在そのものが前回の失敗の原因だった、という反転も作れる）
