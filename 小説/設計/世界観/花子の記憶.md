# 花子が前回の受け手の記憶を見る理由と、回避の手がかり

> AIの検討。決めるのは作者。人物の内面・動機の深さはキャラ担当。
> 2026-11-18 改稿：23年周期をやめたので、「前回の衝突の夜に生まれた」案は使えなくなった。前回の受け手は**数百年前の人**。

---

## 0. 前提（3担当で一致済み）

- 花子は**眠ると**前回の受け手の記憶を**夢で**見る。月の子が近いほど、起きていても見える
- 前回の受け手は、数百年前に月の子を受け、眠ったまま石になり、石積みの**一番上**の石になっている

## 1. なぜ花子に見えるのか（組み直し）

| 案 | 中身 | 効き方 |
|---|---|---|
| A：血 | 花子は前回の受け手の子孫。眠りの器と夢が、血で伝わる | 分かりやすい。ただし花子がこの村の血筋になり、人物関係が強く決まる（キャラ担当に食い込む） |
| B：触れた | 花子は幼いころ、何かの理由で石積みの石（前回の受け手の石）に触れ、そのとき夢がうつった | 単純。理由づけが別に要る（なぜよその子が石積みに触れたか） |
| **C：眠りの底（おすすめ）** | 花子は幼いころ、**眠りすぎた**ことがある（病気、事故、または石の力の暴走で、何年も目を覚まさなかった）。眠りは深いところで一つにつながっていて、そこには石の中で眠っている人たちもいる。花子はそこで前回の受け手と**同じ夢の中にいた**。目を覚ましたとき、その夢を持ち帰ってしまった | 新しい代償「眠り」とそのままつながる。花子の年齢は何歳でもよくなる。太郎の転生理由の候補①「眠りの底」（`石.md` §8）と**同じ場所**を使えるので、二人の秘密が後半で一つにつながる余地がある |

### 案Cの細部

- 花子が持っているのは前回の受け手の**夢のかけら**で、本人そのものではない。花子は花子のまま、他人の無念を自分のことのように感じている（構想メモどおり）
- 前回の受け手は**石積みの一番上で眠り続けている**。花子の夢と、その石の中の夢は、まだ細くつながっている → 花子が石積みに近づくと夢が強くなる。**花子が村に引き寄せられる理由**にもなる
- 花子が「何年も眠っていた子」だとすると、外見と中身の年齢がずれる、などの味付けも可能（キャラ担当へ）

## 2. 何が見えるのか（第一部で使えるかけら）

### ふだんの暮らしのかけら → 第一部で実用になる

- 数百年前の村の道、祠、石積み（今より一段少ない）、当時の人々の口癖や唄
- **花子が村に忍び込めるのは、この夢のおかげ**。ただし**順路は数百年前のもの**なので、今は崩れているところがある（`村の外.md` §2。トラブルに巻き込む偶然として使える）
- 当時の唄や作法を、今の村人も知っている（形だけ残っている）。花子が口ずさむと村人がぎょっとする：「なぜよそ者が、星降り唄の古い節を知っている」

### 最後の数瞬 → 回避の道の匂わせ

第一部で見せるのは、これくらいでよい：

1. 受け場に立つ。雲の上が白く明るい。石積みに手を当て、**根石を握る**（→ 花子が盗むのが根石＝太郎になる理由。`石積み.md` §4）
2. 先代たちの眠りが重なって流れこむ。巨大な重さが近づく
3. 一瞬、ずっと上のほうで、**近づく前の月の子**が見える気がする。「**いまなら、少し押すだけで逸れる**」と分かる。でも遠すぎて手が届かない
4. 「待つんじゃなかった。**迎えに行けば**」。そこで眠りに沈む

花子が分かっているのは「待っていてはだめ」「もっと早く、もっと上で」という感覚だけ。**花子もよく分かっていない**（構想メモどおり）ので、太郎とモメる。

- 物理的にも筋が通る：かすめて去る天体は、**遠くで少し押せば**大きく逸れる。近づいてからでは止められない（`衝突.md` §3）
- テーマ：**村で待つこと＝繰り返し、迎えに行くこと＝村を出ること**。台詞で言わずに、仕組みで出る

## 3. 太郎との関係で起きること

- 太郎は**夢渡り**で花子の夢に入れる（`石.md` §3, §5）。眠れない太郎が「まどろみ」を味わえる唯一の場所が花子の夢 → 太郎は花子の夢の中で、前回の受け手の最期を**自分も見てしまう**
  - 太郎にとって、花子の話が「信じるしかない話」から「自分も見た話」に変わる瞬間（使うなら第一部の後半）
- 前回の受け手が握っていたのは**根石**だった → 前回の受け手は、最期に太郎に触れていた。**太郎は何百年も前に、この人の手を知っていたかもしれない**（太郎がそれを覚えているかどうかは、転生理由と一緒に温める）

## 4. 第一部ではやらないこと

- 回避の方法を具体的に説明しない（「迎えに行く」の手段は第二部以降）
- 眠りの底がどういう場所なのかを説明しない（花子の夢の質感として見せるだけ）
