## 大きな嘘（一つだけ）

**宇宙は、もっと次元の多い空間（バルク）に浮かぶ、無数の膜の一枚。古代の人は、別の膜へ通じる「口」を開く方法を見つけた。口を固めたものが「石」。**

- 現実の物理の仮説（ブレーン宇宙）を下敷きにしている。膜の外に漏れられるのは重力だけ
- **この世界の膜は、隣の膜とたまたま近い。** だから口が開きやすい（なぜ近いのかは、奥の謎）

## 表と裏（案。作者「もう少し詳しい人も唸る感じにするか、ディメンションWくらいシンプルなのがいいね」）

**表（読者に見せる。ディメンションWくらいシンプルに）**
> この世界のすぐ隣には、別の決まりで動く世界がいくつも重なっている。石は、その世界への「窓」。窓は、向こう側を知る者が見ているあいだだけ開く。

- 作中の呼び名の候補：隣の世界＝「**常世（とこよ）**」（古い日本の言葉で、海の彼方にある別の世界）／石＝「**窓石**」「要石」
- 読者が覚えるのは三つだけ：①石は窓 ②窓の向こうの決まりが、こちらで力になる ③窓を開けておけるのは、向こうから来た心だけ

**裏（詳しい人が唸るための裏付け。本文では手がかりとして少しずつ）**
| 作中のこと | 裏付け（現実の物理の考え・仮説） |
|---|---|
| 隣にいくつも世界がある | ブレーン宇宙（膜とバルク）。膜の外に漏れられるのは重力だけ |
| 世界ごとに決まりが違う | 超ひも理論の「真空のランドスケープ」：物理定数の違う宇宙（真空）が、ものすごい数ありうる |
| 窓 | 二枚の膜をつなぐ、バルクを通る細い通り道（通り抜けられるワームホールの考え） |
| 窓を開けておくには燃料が要る | 通り抜けられるワームホールを保つには、負のエネルギーのような特別なものが要る、とされている |
| 傾ける・浮かべる | 窓は時空の形そのもの。窓の形を変えると、まわりの重力（時空の曲がり）が変わる |
| しまったものは時間がほとんど進まない | 時空が強く曲がった場所では、時間がゆっくり進む（重力による時間の遅れ） |
| 窓は、両側を見る者がいるときだけ開く | 量子力学の「見続けると変化が止まる」現象と、「結果は、誰から見た結果かで決まる」という解釈（関係解釈）を下敷きにした、作品の嘘 |

## 石

| | 電池の石 | 要の石 |
|---|---|---|
| 口 | 閉じたまま固めてある | 開いたまま。形を変えられる |
| できること | エネルギーをためて出す。遺物の燃料、村の暖房や灯り | つながる先の宇宙の決まりで、こちらの世界に働きかける |
| 数 | たくさんある規格品 | ごくわずか |
| 中に人は | いない | **いる** |

- **要の石は、それぞれ別の宇宙につながっている。その宇宙の物理の決まりが、石の力になる。** 掘り出す石ごとに、力が違う
- **太郎の石**：力は「空間を傾ける」（動かす・浮かべる・飛ぶ）と「しまう・出す」（しまったものは時間がほとんど進まない）。つながる先は未決
- **要の石に人が入っている理由**：口は、**見続ける観測者がいるあいだだけ開いている**（量子力学の「見続けると変化が止まる」現象を下敷きにした作品の嘘。機械の観測では足りず、人の心でなければならない）。だから太郎は眠れない
- **制約**：燃料が要る／中の人が素人（大きな操作や同時操作に頭が追いつかない）
- **切り札**：燃料を一気に使って、大きく曲げる。使ったあとは、しばらく何もできない
- **成長**：太郎が使いこなしていく。かけらを戻すと力が戻る、の線も残す
- **遺物**：どれも石を差すと動く。船、外骨格、雪上の乗り物、空を飛ぶ台、番犬の機械など。巨大な人型の機械は出さない
