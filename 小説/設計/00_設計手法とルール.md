# 設計手法とルール

> 2026-11-17 確定（作者「まかせる」）。要点は `CLAUDE.md` にも書いてある。

## 1. 設計の進め方（上から順に。戻ってよい）

| 段階 | やること | 書く場所 | 書く人 |
|---|---|---|---|
| 0. 欲求 | 書きたいもの・やりたいことを出す | `構想メモ/` | 本人 |
| 1. 芯 | コンセプト1行、テーマ（作中では言わせない）、敵（例：繰り返し・停滞） | `設計/決定ログ.md` | AIが本人の決定を記録 |
| 2. 人物 | 人物ごとに、欲しいもの（水一杯の小さい欲求／大きい欲求）、邪魔するもの、弱点、変化 | `設計/キャラ/` | AI案 → 本人が決める |
| 3. ビート | 部ごとに10場面前後。1行ずつ「誰が何を欲しがる／何が邪魔する／何が変わる」 | `設計/プロット/` | AI案 → 本人が決める |
| 4. 場面カード | ビート1つにつき1枚。上の3つに加えて「この場面に必要な設定」 | `設計/プロット/` | AIと本人 |
| 5. 本文 | 場面カードをもとに書く | `本文/` | **本人だけ** |
| 6. 振り返り | 本文への講評。設計に戻す点を出す | `設計/講評/` | AI |

**設定（世界観）は、場面が必要とするときだけ作る。** 世界観を先に積み上げない。これがワールドビルダー病への対策。使わない案は `設計/倉庫.md` に置いておく。

## 2. ルール

### 本人の文とAIの文を分ける
- `構想メモ/` と `本文/` には本人の文だけを置く。AIは本人の文を書き換えない。本人がチャットに書いた文を、そのまま貼るのはよい。
- 構想メモは日付ごとに1ファイル（`構想メモ/YYYY-MM-DD.md`）。同じ日の分は追記していく。古い案も消さない（考えた経緯を残すため）。
- AIの提案・講評・整理は、すべて `設計/` に書く。

### 決めるのは本人
- AIは「選択肢＋おすすめ」の形で出す。決まったことのようには書かない。
- 本人が決めたことは、AIが `設計/決定ログ.md` に日付つきで記録する。元になった本人の発言の場所も書いておく。
- 設計どうしで食い違ったら、決定ログのほうが正しいとする。

### 書く前の点検（どの提案にも当てる）
1. 主要な人物は全員、何かを欲しがっているか（水一杯でもいい）
2. トラブルから**助ける**のが偶然になっていないか（トラブルに巻き込む偶然はよい）
3. テーマを台詞で言わせていないか
4. その設定は、どれかの場面に必要か（必要でなければ倉庫へ）
5. 「すごくやりたい」3つ（発掘・収集／一歩引いて青春を見守り、自分も成長する／お互いになくてはならない）につながっているか

### 講評
- 書いた本文には、頼まれなくても講評をつける。厳しさは「率直・具体的」にする。良いところも書く。直すべき点は、重要な順に最大3つまでにする。
- 文章を直した例を見せる場合も、本文のファイルは触らず、講評の中に例として書く。

### 子セッション（ネステッドセッション）
- お題1つにつき、子セッション1つ、フォルダ1つ。子セッションは自分のフォルダにだけ書く。
- push は、子セッションごとの自分のブランチにする。取り込みと食い違いの整理は、マスター（親セッション）がやる。
- **重要なことはマスターに連絡する。** 連絡するのは次のとき。
  - 作者に決めてもらう必要が出たとき
  - ほかのお題と食い違いそうなとき、またはほかのお題の結果に依存するとき
  - 構想メモの方針から外れる提案をしたいとき
  - 作業を終えたとき
- 連絡の方法は `send_message`。送れなかった場合は、自分のフォルダの `連絡.md` に書いて push する（マスターがそれを読みに行く）。
- 子セッションの成果は「案」として扱う。決定ログに記録されるまでは確定ではない。

## 3. フォルダー構成

```
小説/
  構想メモ/            本人の構想（日付ごと、追記だけ）
  本文/                本人の原稿（第01話.md …）
  設計/                AIが書く
    00_設計手法とルール.md
    決定ログ.md        本人が決めたことの記録
    倉庫.md            今は使わない案の索引
    提案/              マスターでの提案
    キャラ/            人物（子セッション）
    世界観/            石・衝突・村など（子セッション）
    プロット/          ビート、場面カード（子セッション）
    講評/              本文への講評
```
