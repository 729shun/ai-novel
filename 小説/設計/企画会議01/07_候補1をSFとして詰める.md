# 候補1をSFとして詰める

> マスターの案。作者「取り立てとかなんか、ふわっとしてるのできちんとSFにしてほしい」。決めるのは作者。
> 方針：「借り」「取り立て」「質草」を、たとえ話ではなく**物理の現象と、それを扱う人々の仕事**として説明できるようにする。言葉もやさしくする。

## 一言で

> **石は、隣の宇宙と「重さ」をやりとりする装置。やりとりした分は、必ず釣り合いが戻ろうとする。**

## 仕組み（3つ）

| 決まり | 中身 | 現実の物理の下敷き |
|---|---|---|
| 1. 重さは、隣の宇宙とやりとりできる | 石は、この宇宙の重さ（重力のエネルギー）を、すぐ隣の宇宙へ逃がしたり、引き込んだりできる。逃がせば物は軽くなって浮き、引き込めば重くなって落ちる | 重力だけは、この宇宙の外（余剰次元）に漏れているかもしれない、という仮説 |
| 2. 釣り合いは、必ず戻ろうとする | 二つの宇宙をまとめて見ると、エネルギーは増えも減りもしない。片方に寄せた分だけ、石のまわりの空間に**歪み**がたまる。歪みはばねのように、元に戻ろうとする | エネルギー保存則／時空の歪み（一般相対性理論） |
| 3. 落ちている物しか、つかめない | 石がつかめるのは、**落ちている物**（落下中の雪、雪崩、投げられた石）だけ。地面に立っている物や、人はつかめない | 等価原理：落ちている物は、自分の重さを感じない（重力から切り離された状態）。だから、こちらの宇宙の重さの勘定から外しやすい |

## ふわっとしていた言葉を、こう置き換える

| 前の言葉 | これから | 中身 |
|---|---|---|
| 借り・残高 | **歪み** | 石のまわりにたまった、釣り合いのずれ。ステータス画面には「歪み」の数値が出る |
| 取り立て | **揺り戻し**（自然の現象） | 歪みがたまりすぎると、ばねが戻るように、一気に元に戻る。そのとき、預けていた重さが一度に返ってくる（物が一斉に重くなる、落ちる） |
| 取り立ての役人 | **歪み見（ひずみみ）**（人の仕事） | 揺り戻しで町や村が潰れないように、各地の歪みを測って回り、危ない石を止める人たち。空の上の人々の仕事 |
| 質草 | **おもり** | 石の中にしまわれた物。前の住人たちが、歪みを打ち消すために預けた**釣り合いのおもり**。一つ取り出すと釣り合いが崩れるので、別のところで釣り合いを取り直さないといけない |
| 最初から残高がマイナス | **最初から歪みが限界近く** | この石は、昔の文明が空の町を浮かせるために、一番たくさん重さを逃がしていた石。その歪みが、何千年も残っている |

## 世界への広がり

- **空の上の人々：** 昔の文明が、重さを隣の宇宙へ逃がして浮かせた町に住んでいる。町が浮いていられるのは、地上のこの石に、その分の歪みがたまっているから
- **だから、娘（歪み見の見習い）がこの村に来る：** 村の御神体の歪みが、急に動いた（太郎が転生して、雪崩をつかんだから）。揺り戻しが起きたら、村だけでなく、空の町も落ちるかもしれない。止めに来た
- **太郎と娘がぶつかる理由：** 娘は「危ないから石を止めたい」。太郎と村は「石を止めたら、次の雪崩から村を守れない」
- **二人がなくてはならない理由：** 太郎は、歪みを少しずつ安全に戻す方法を知らない。娘は、歪みを測れるが、石を動かせない
- **雪解けの日の締め切り（前の案）は外す：** 代わりに「歪みの限界」が締め切りになる。ステータス画面の数値が、そのまま時計になる

## 小プロット（この言葉で書き直したもの）

| 幕 | | |
|---|---|---|
| 起 | 1 | 雪国の村の守り神の丸い石に、会社員が転生する。落ちてくる雪崩をまるごとつかんで止めるが、目の前に出た数値は「歪み 限界まであとわずか」。 |
| | 2 | 空の上の町から、歪み見の見習いの娘が、危ない石を止めに来る。止めたい娘と、止められたくない石が、ケンカしながら手を組む。**【第一転換点】** |
| 承 | 3 | 石の中には、前の住人たちが釣り合いのために預けたおもりが眠っている。一つ取り出すたびに使える道具が増えるが、釣り合いを取り直す工夫が要る。その一つが、船の舵だった。 |
| | 4 | 舵が指す雪の下から、古代の船を掘り当てる。船は、石の重さのやりとりで雪の上を走り、跳ぶ。**【中間点】** |
| 転 | 5 | この石の歪みが、空の町を浮かせていると分かる。歪みを戻せば村は安全になるが、空の町は落ちる。 |
| | 6 | 歪みが限界を超え、揺り戻しが始まる。太郎は一人で全部受け止めようとして、動けなくなる。**【どん底】** |
| 結 | 7 | 娘が歪みを測り、村人が雪を落とす係を受け持ち、太郎が少しずつ重さを戻す。揺り戻しを、村も空の町も潰さずに逃がしきる。**【山場】** |
| | 8 | 娘は、空の町の人々を、いつか安全に地上へ降ろす方法を探すため、太郎と船で旅に出る。 |

## 決めてほしいこと

1. 「借り・取り立て」を「歪み・揺り戻し・歪み見」に置き換える形で、SFとして納得できるか
2. 「落ちている物しか、つかめない」（等価原理）は、制約として面白いか
