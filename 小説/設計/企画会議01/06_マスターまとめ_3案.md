## 候補1「残高マイナスの御神体」（編集者の合わせ技＋読者の要望）

**大きな嘘：** 重さだけは、宇宙の外と貸し借りできる。

**石のしくみ：** 重さを預かる（しまう）・払い戻す（出す）。重さを抜いた物は浮き、足した物は落ちる。残高は「重さ×高さ」で数える（持ち上げると減り、落とすと増える）。預かれるのは、落ちてくる・積もった・投げられた重さだけ（立っている生き物は預かれない）。冬に預かった物は、雪解けの日に必ず返る。

| 幕 | | |
|---|---|---|
| 起 | 1 | 星降りの夜、雪国の村の御神体の丸い石に、徹夜明けの会社員が転生する。村を襲った雪崩を丸ごと預かって消し、初めて見えた帳簿の残高は、最初からマイナスだった。 |
| | 2 | 年に一度の取り立て便で、空の上から石改めの見習いの娘が来る。刻印のない規格外の石を没収しに来た娘と、取り立てを嫌う村と石が、喧嘩しながら手を組む。**【第一転換点】** |
| 承 | 3 | 石の中には、前の住人たちが重さを借りるときに入れた**質草**が眠っている。一つ請け出すたびに使える道具が増え、借りも増える。その一つが、船の舵だった。 |
| | 4 | 舵が指す雪の下から、古代の船を掘り当てる。重さを流すと、船は雪の上を走り、跳ぶ。娘は初めて、空からではなく地上から、空を見上げる。**【中間点】** |
| 転 | 5 | 帳簿の一行だけが、太郎の字にそっくりだと気づく。前の住人たちは、借りを返しきれずに消えていた。 |
| | 6 | 雪解けの日が来て、冬じゅう預かった雪崩が村に返ってくる。太郎は一人で全部を抱えようとして、残高が底を抜ける。**【どん底】** |
| 結 | 7 | 太郎は、娘と村人に重さを分けて受け持ってもらう段取りを組み、返ってきた雪崩を、船ごと空へ投げ返して春の雨にする。**【山場】** |
| | 8 | 娘は、空の上の人々を地上に連れて帰る日を夢に、船で次の村へ向かう。帳簿の太郎そっくりの一行は、まだ読めない。 |

- **あらすじ三行：** 御神体の丸い石に転生した会社員。力は「重さの貸し借り」——だが残高は最初からマイナスで、中には前の住人たちの質草が眠っていた。取り立てに来た見習いの娘と、質草を請け出し、雪の下の船を掘り起こす。
- **相棒の夢：** 空の上の人々（重さが足りなくて地上に降りられない）を、いつか地上に帰すこと
- **圧倒的な一撃：** 1話で雪崩を丸ごと消す／山場で、返ってきた雪崩を空へ投げ返す
- **宣言する謎：** 帳簿の一行だけ、なぜ太郎の字なのか
- **1巻に出すもの：** 村・石・船・娘・マイナス残高・質草（数品）・雪解けの締め切り。ライバル（重さを踏み倒して自由に飛ぶ、かっこいい転生者）は1巻の最後に影だけ
- **リスク：** 要素が多い（1巻は上の五つに絞る）／空の民と浮く船は『天空の城ラピュタ』に近づくので、娘は空から落ちてこない・船は基本は雪の上を走る

## 候補2「しまい忘れの倉庫」（読者が一番素直にワクワクした案）

**大きな嘘：** 宇宙と宇宙のあいだを渡るものは、丸い石に引っかかる。

**石のしくみ：** 引っかかった物（魂も物も）を中にしまい、取り出せる。取り出した物の位置を握っているので、飛ばす・止める・自分ごと浮く。ただし、**正体（名前）が分かった物しか、もう一度しまえない**。正体不明の物を出すと、出しっぱなしになる。中身の一覧は最初から見えている（「品目108、正体の分かる物0」）。

| 幕 | | |
|---|---|---|
| 起 | 1 | 会社員が、村の御神体の丸い石に転生する。村の子に投げられた石は空中で止まって戻り、驚いた拍子に、中から錆びた刀がこぼれ出る。「……なんか入ってる」 |
| | 2 | 太郎は、自分がこの石の48代目の住人で、中に前の47人のしまい忘れが108品眠っていると知る。雪市を渡り歩くよそ者の少年鑑定屋が、刀の正体を当てた瞬間、刀は太郎のまわりを回り始める。**【第一転換点】** |
| 承 | 3 | 一章に一品、正体を突き止めて、使える道具にしていく。少年の夢は、誰も見たことのない古代の遺物を、自分の目で鑑定すること。 |
| | 4 | 品の一つが、船の舵だった。舵が指す先を掘ると、雪の下から古代の船体が現れる。自分の中を掘る話が、外を掘る話になる。**【中間点】** |
| 転 | 5 | ステータスの備忘録に、誰も書いていない一行が増えていく。筆跡は、前の住人の誰か——いや、太郎自身のものに似ている。 |
| | 6 | 網に入れなかった49人目の転生者が、太郎の中身を奪いに来る。太郎は正体の分からない品を一人で出して戦い、止められずに村を壊しかける。**【どん底】** |
| 結 | 7 | 太郎は少年と村人に品を一つずつ預け、それぞれの手で使ってもらって、49人目を退ける。**【山場】** |
| | 8 | 船を動かし、少年は初めて村の外の空を見る。備忘録の最後の一行には、「次の自分へ」と書いてあった。 |

- **あらすじ三行：** 御神体の丸い石に転生した会社員は、その石の48代目の住人だった。中には47人のしまい忘れが眠り、正体が分かった物だけが自在に使える。口の悪い鑑定屋の少年と、自分の中を掘りながら、前の住人たちの行方を追う。
- **相棒の夢：** 誰も見たことのない古代の遺物を、自分の目で鑑定すること
- **圧倒的な一撃：** 正体不明の品を一か八かで出したら、山を一本削って村に道ができた（3話あたり）
- **宣言する謎：** 備忘録の文字は誰の筆跡なのか（一行だけ太郎の字にそっくり）
- **リスク：** 何でも出てくる箱に見える（中身の数と形を最初に見せ、中身は前の文明の物に絞る）／少年がいないと何もできない（太郎も、形や傷から自分で推理できるようにする）

## 候補3「地図の空白」（村の外の景色が一番強い案。明るく直したもの）

**大きな嘘：** 誰にも見られていない物は、重さが決まっていない。

**石のしくみ：** 太郎の石は、見つめた物の重さを決める・決め直す（浮かせる・飛ばす・止める）。まばたきがないので、いくつもの物を同時に見つめられる。見えない物には何もできない（背後・暗闇・霧）。自分自身は見えないので、自分を浮かせるには誰かに見てもらう。

| 幕 | | |
|---|---|---|
| 起 | 1 | 会社員が、村の御神体の丸い石に転生する。冬祭りの石投げで投げられた太郎は、見物人の視線で飛距離を伸ばし、村の外まで飛んでいく。 |
| | 2 | 村の外には、重さの決まらない古代の遺物が、雪原の上にいくつも浮かんでいた。太郎を拾ったのは、地図の空白を埋めに来たよそ者の測量士の娘。**【第一転換点】** |
| 承 | 3 | 太郎が浮かぶ遺物を見つめて地面に下ろし、村は初めて外の物を手に入れる。排他的な村人も、娘の地図と太郎の目を少しずつ頼るようになる。 |
| | 4 | 二人は、見つめて重さを決めた土地を、一枚ずつ地図に描いていく。描いた土地は人が歩ける土地になり、村の居場所が広がる。地図の端には、空に浮いたままの古代の町が見えてくる。**【中間点】** |
| 転 | 5 | 冬祭りの石投げの日、各地の御神体が集まる。その中に、太郎と同じ「見張りの石」と、中に入ったもう一人の転生者がいた。 |
| | 6 | 霧の夜、相手の石に村の重さを決め直され、霧の中で何も見えない太郎は、何もできない。**【どん底】** |
| 結 | 7 | 娘が太郎の目になって背負って走り、村人みんなが太郎を見つめて、太郎自身を空へ飛ばす。太郎は霧の上から、相手の石を見つける。**【山場】** |
| | 8 | 地図に、村と、浮かぶ古代の町までの道が描き足される。娘の夢は、世界の地図を全部埋めること。 |

- **あらすじ三行：** 誰にも見られていない物は、重さが決まらない世界。雪国の村の御神体に転生した会社員は、一瞬も目を閉じない「見張りの石」だった。地図を描くよそ者の娘を目にして、村の外の、浮いたままの土地を見つめに行く。
- **相棒の夢：** 世界の地図を、全部埋めること
- **圧倒的な一撃：** 1話で、投げられて村の外まで飛んでいく／山場で、村人みんなの視線で空へ飛ぶ
- **古代文明の絵：** 雪原の上に浮いたまま止まっている、古代の町
- **宣言する謎：** なぜ国の地図には、村の場所だけが空白なのか
- **リスク：** 観測の理屈は物理好きに突っ込まれやすい（作中で理屈を語らず、言葉として使う）／霧の中の見えない敵が怖くなりすぎないよう、明るさを保つ
