# 最小プロット（山奥屋式）

> AIの叩き台。作者「その方法で最小プロット作ってみて」。決めるのは作者。
> 賀東招二「山奥屋」の手順どおりに作った：①やりたいもの（「すごく、すごくやりたい」に印）→ ②接着剤をたくさん出して、いったん忘れる → ③やりたいものを元に、起承転結2行ずつの最小プロット。
> 山奥屋の言うとおり、この段階では**ベタでよい**（何が起きるのかだけを書く。面白さは、すごくやりたいものが入っているかで見る）。名前は使わない。

## ① やりたいもの（作者の構想メモから。言葉もなるべくそのまま）

- 発掘やオーパーツ。レア物や収集のワクワク **（←すごく、すごくやりたい）**
- 一歩引いた位置で青春を見守る、自分もいっしょに成長する **（←すごく、すごくやりたい）**
- お互いになくてはならない **（←すごく、すごくやりたい）**
- 人以外に転生する
- バディものでの掛け合いやツッコミ
- 自分を中心に仲間がどんどん増えて、居場所ができる
- 同じ力を持つ者どうしの戦い
- スピード感のあるSF異能バトル
- 船を手に入れる、新しい機体のような遺物を発掘する
- ファンタジーSFで、遠い未来の生活を描く／宗教、自然、高度な古代文明
- 閉じた境界から出ていく／隠された秘密がある
- 排他的な村人が、中に入れば親切（だから相棒はよそ者）
- 東北の冬くらいの雪国
- 最後に「また積もるのに」とは思わない

## ③ 最小プロット

|---|---|
| 起 | 会社員が、雪国の村の御神体の丸い石に転生する。石は、何百年分の力をため込んでいた。 |
| 起 | 遺物を掘りに来たよそ者の少女に拾われ、ケンカしながら組んで、村の外の遺跡へ出る。 |

## すごくやりたい3つが入っているか

| すごくやりたい | どの行 |
|---|---|
| 発掘・オーパーツ・レア物・収集 | 承1（遺跡を掘っては、遺物や船を手に入れる） |
| 一歩引いて青春を見守る、自分も成長する | 承2（少女が育つのを見守り、自分も覚えていく） |
| お互いになくてはならない | 起2（組む）→ 転2（一人で抱えて負ける）→ 結1（互いを信じて力を合わせる） |

## 次（山奥屋の手順）

この8行の1行を4行くらいに膨らませて、中プロット（A4一枚）にする。そのとき、②の接着剤を使い、まずは「お約束」に忠実にやる。
