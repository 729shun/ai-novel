## 第一幕：村を出る（〜25%）

### 小プロット

1. 暗闇で目覚めた太郎は石だった。雪に埋まると意識が薄れる。毎朝、老人と大志が雪を払ってくれる。太郎はこっそり屋根の雪を落としてやる。「どうせまたつもるのに」
2. 村の祭壇には、歴代の受け手が石になって積まれている（石積み）。衝突が巡ってくると知り、太郎は「次は大志がこの上に積まれる」こと、そして自分がどうなるか分からないこと（**世界観次第**：上書きされる／一緒に積まれて眠る）を知る。「ここから出たい」
3. 花子が石を盗む。太郎は外に出たいのに、花子を信じない。花子が力を使うたびに、その場で眠りこけ（代償は眠り）、太郎はそのたびに雪原に放り出される
4. 大志の追手。太郎が協力しない（＋勝手に重くなる）せいで、花子は捕まる。石は村へ戻る
5. 掟により花子は追放と決まる。追放とは、底なしの縁から外へ出されること。石は村に残る
6. 夜、太郎は初めて大志に声をかけ、「頼む」と言う。大志は迷った末、追放の朝、縁に立つ花子へ石を投げる（または自分の手で渡す）
7. 花子は石を握って底なしへ落ちる。落ちながら、太郎は初めて花子の言う通りに力を使う（重さを軽くする）。花子は着地と同時に眠りこける。上から大志の声：「借りは返した。次は取り返す」

### 太郎の変化

誰にも気づかれずに働く → 出してくれる人を信じない → **初めて頼む**（大志に）／**初めて言う通りにする**（花子に）

### 大きな転換点（第一幕の終わり）

**底なしへ落ちる。** 閉じた境界の外へ出る。ただし「出た先は上ではなく下」。太郎の期限（衝突）は残ったまま。

## 第二幕 前半：底なしの下で掘る（25〜50%）

### 小プロット

1. 底なしの下は、地下世界。凍った古い街、地下の温泉、竪穴、野生化したロボット犬（倉庫から）。落ちてきた者たち（追放者の子孫）が細々と暮らしている。上の村々を「天井」と呼ぶ
2. 地下には、**巡りを受け止めきれずに滅んだ村**が沈んでいる。そこにも石積みがある。花子の記憶（「鳴りがそろっていなかった」「押せたかもしれない」）を頼りに、二人は滅んだ村の石を掘り始める
3. 掘り出した石には、それぞれ先代の人格が入っている（ソーディアン）。口うるさい婆さまの石、自分を石だと思っていない子どもの石、など。**太郎の同類が増える。**「石同士だと話せる」ことに太郎は戸惑う。初めての同僚
4. 花子は力を使うたびに眠り、眠ると前回の受け手の夢を見る。太郎は花子が寝ている間、石たちと見張りをする。**太郎が「任せる」練習をする場**になる（地下の人々や石たちに段取りを任せ、口を出したくてうずうずする）
5. 地下の人々は「天井には戻れない」と思っている（繰り返しのもう一つの形：落ちた者はずっと落ちたまま）。花子と太郎は、地下の人々の頼みごと（ロボット犬を追い払う、温泉を掘り直す）を手伝ううちに、居場所ができていく
6. 砂に埋もれた古い飛空艇を掘り当てる。動かすには「鍵」の石が要る。太郎だけでは動かない。**集めた石を並べて鳴りをそろえると、船が目を覚ます**（小さな「押し返し」の予行）
7. 船で天井（地上）へ上がる。地下の人々の何人かがついてくる

### 太郎の変化

頼む → **任せる**。自分がやったほうが早いことを、人（と石）にやらせて待てるようになる。ただし、まだ「報われたい」とは言えない

### 中間点（50%）

**飛空艇で地上に戻る。** 「下に落ちた者は戻れない」という繰り返しを、初めて破る。偽りの勝利：石は集まり、船もある。花子は「これで衝突を押し返せる」と確信する

## 第二幕 後半：同じ力を持つ者（50〜75%）

### 小プロット

1. 地上の空で、配給の飛空艇に乗った大志と再会する。大志は村の石積みから先代の石を持ち出していた（問3でA）。**同じ力を持つ者どうしの戦い。** 大志の先代の石は、太郎とは逆に「受け止めろ」と言い続ける人格
2. 配給の飛空艇の人々（上の人々）は、巡りを管理している側。村に配給を配り、受け手を育てさせ、衝突の熱を集めている（**世界観次第**：熱をどこに送るか。倉庫の「火星」「砂」につながる）。悪人ではない。「受け止めないと、世界中が凍える」と本気で信じている
3. 二人は各地の村を回り、石の鳴りをそろえる仲間を探す。村ごとに受け手がいて、村ごとに閉じている。ある村は花子たちを迎え、ある村は追い返す。大志とは何度もぶつかり、そのたびに大志の考えが少しずつ揺れる（花子が見る夢の中の受け手は、大志と同じことを言っていた）
4. 花子の記憶の答えが、間違っていたかもしれないと分かる。前回の受け手は「押せた」のではなく、**押そうとして失敗し、そのせいで村が一つ滅んだ**（それが地下に沈んだ村だった）。花子の使命は他人の無念で、しかもその無念は誤解だった。花子が崩れる
5. 衝突が近づく。上の人々は、各地の石を集めた花子たちから石を取り上げようとする。花子は使命を見失って動けない
6. **太郎のどん底（問5でA）：** 太郎は「できる人がやるしかない」と、自分ひとりを差し出して受け場に立とうとする。花子にも石たちにも相談せずに。大志に「俺を持っていけ。おまえは積まれなくていい」と言う。誰も信じない人の、最悪のやり方

### 太郎の変化

任せる → **また全部抱え込む**（逆戻り）。ただし今度は、抱え込んでいることを自分で分かっていて、それでもやめられない

### 大きな転換点（75%）

**太郎が自分を差し出す。** そして止められる。止めるのは花子（眠りの借りを溜めすぎて倒れかけながら）、または大志（「積まれるのは俺の役目だ。勝手に盗るな」）。どちらが止めるかでラストの形が変わる（別案ファイル参照）

## 第三幕：押し返す、帰る（75〜100%）

### 小プロット

1. 太郎は初めて、自分の欲しいものを口にする。「消えたくない。……終わったら、眠りたい。ちゃんと」。報われたいという願いの、いちばん小さい形
2. 花子は使命を自分で選び直す。前回の受け手の無念のためではなく、「この石（太郎）と、このあとも口げんかしたいから」程度の、自分の理由で
3. 大志は役目を自分で選び直す。受け止めるのではなく、押し返す側の受け手として受け場に立つ。先代の石と、初めて言い争う
4. 衝突の夜。各地の村の受け手、地下から来た人々、集めた石たち、そして大志と花子と太郎。**鳴りをそろえるには、全員が自分の役を信じて任せるしかない。** 太郎は全部を自分で抱えたいのを我慢して、自分の役だけをやる
5. 衝突を押し返す（問2でA）。上の人々の飛空艇も、最後に手を貸す（または貸さない。**世界観次第**）。代償で、力を使った全員がいっせいに眠りこける（コミカルな着地）
6. 目を覚ますと、雪が降っている。巡りは終わった（か、ずっと先へ遠のいた）。でも雪は降る

### 太郎の変化

抱え込む → **信じて任せる** → **報われたいと願える**（眠りたいと言える）

### ラスト（エピローグ）

村に帰る。石積みには、もう新しい石は積まれない（大志は石にならなかった）。代わりに、太郎は石積みのいちばん上に、みんなに置かれる。朝、老人と大志が雪を払う。雪はまたつもる。太郎は**「またつもるのに」とは思わない**。思わないことを、台詞にしない。
（雪かきの詩：「今日もまた、雪をかく」）

## 「つもる」と「眠り」の使い方

### つもる（雪が積もる／石が積まれる）

| 場面 | つもるもの | 太郎の受け取り方 |
|---|---|---|
| 第一幕の冒頭 | 雪 | 「どうせまたつもるのに」 |
| 第一幕 2 | 石積み（歴代の受け手） | 「次は大志がこの上に積まれる」。雪と同じく、どうせまた積まれる |
| 第二幕 前半 | 滅んだ村の石積み（崩れている） | 積む人がいなくなった石積み。繰り返しが止まると、こうなる |
| 第二幕 後半 | 花子の眠りの借り（使うほどつもる） | 花子に力を使わせたくない理由 |
| ラスト | 雪。そして石積みのいちばん上に太郎 | 「またつもるのに」とは思わない |

**台詞で言わせない。** 「つもる」を口にするのは冒頭の太郎の心の声だけにして、ラストは同じ景色だけを見せる。

### 代償の眠り（コミカルに）

- 花子は力を使うと、その場で寝る。量は才能で違う（花子はたくさん使えるが、そのぶん借りもたまる）。逃げている最中でも寝る → 太郎が「起きろ」と言えない（動けないので）
- 太郎の小さい欲求は「眠りたい」なのに、眠るのは花子ばかり。太郎は眠れない（**世界観次第**：石は眠りの借りをためない？）
- 花子が眠ると前回の受け手の夢を見る（キャラ・世界観の案）→ **力を使うほど、他人の無念を夢で見る**。笑いと重さが同じ仕組みから出る
- 第二幕後半：眠りの借りをためすぎると、目を覚まさなくなる（**世界観次第**）。山場の緊張に使える
- ラスト：全員がいっせいに寝る。太郎も初めて眠れる（問：石も眠れるのか → 世界観次第）

## 点検（ルールの5項目）

| 項目 | 結果 |
|---|---|
| 1. 主要人物は全員何かを欲しがっているか | ○ 人物ごとの表のとおり。上の人々も「世界を凍えさせたくない」 |
| 2. 助けるのが偶然になっていないか | ○ 第一幕の救出は大志の選択。中間点の船は花子と太郎が掘り当て、石を並べて動かす。第二幕後半の太郎を止めるのは花子か大志の選択。第三幕は全員の選択。※地下世界に落ちるのは「巻き込む」側なので偶然でよい（ただし追放という掟の結果なので偶然ですらない） |
| 3. テーマを台詞で言わせていないか | ○ 「繰り返し」は、雪・石積み・毎朝の祈り・落ちた者は戻れない・村ごとに閉じている、で見せる。ラストも台詞なし。※第三幕1の太郎の「眠りたい」は欲しいものの台詞で、テーマの説明ではない |
| 4. その設定は場面に必要か | ○ 倉庫から拾ったものは、使う場面を表に書いた。使わないものは倉庫のまま |
| 5. 「すごくやりたい」3つにつながるか | ○ 上の表。第一部で弱かった発掘・収集は、第二幕前半を丸ごと発掘にして補った |
