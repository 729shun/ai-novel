# 最小プロット（叩き台）

> AIの叩き台。**選ぶのと書き直すのは作者**（`00_設計手法とルール.md` ③）。
> 山奥屋の書き方：7〜8行、起承転結を2行ずつ、何が起きるのかだけを書く。名前・年齢・設定の説明は書かない。
> 元にしたもの：構想メモ（小プロット2、2026-11-18の決定）、決定ログ。人物は役割で呼ぶ：**石**（現代の会社員の意識が入った石）、**女**（石を盗む）、**少年**（次の受け手）。

---

## 案A：外へ出て、迎えに行く（三幕構成のおすすめ案を縮めたもの）

| | |
|---|---|
| 起 | 雪に閉ざされた村で、受け手たちが積み上げてきた石の一番下にいる石は、次の大きな衝突で自分が潰れると知る。 |
| 起 | 女が石を盗み出すが、石は女を信じず手を貸さないので、女は捕まって底なしの外へ追放される。 |
| 承 | 石は初めて少年に頼み、少年は石を女に渡す。石と女は底なしへ落ちる。 |
| 承 | 底の世界で、二人は滅んだ村の石を掘り集めて仲間を増やし、古い船で地上へ戻る。 |
| 転 | 同じ力を手にした少年とぶつかりながら村々を回るうちに、女の使命が誤解だったと分かり、女は崩れる。 |
| 転 | 石は自分ひとりを差し出して衝突を受けようとするが、女と少年に止められる。 |
| 結 | 石と女と少年、村々と集めた石が力を合わせて、衝突を迎えに行って逸らす。 |
| 結 | 力を使った全員が眠りこけ、目を覚ますと、また雪が積もっている。 |

- **良いところ：** 「すごくやりたい」3つが全部入る。話の幅が広く、すぐには終わらない。
- **弱いところ：** 承と転に出来事が多い。ここを中プロットに膨らませると、一冊では収まらないかもしれない（シリーズ向き）。

## 案B：集める旅（発掘・収集を真ん中に）

| | |
|---|---|
| 起 | 一番下の石は、次の衝突で自分が潰れると知る。 |
| 起 | 女が石を盗み、二人は掟を破った者として村を追われ、底なしへ落ちる。 |
| 承 | 衝突を逸らすには各地の石が要ると知り、二人は底の世界と地上の村々を回って、人格の入った石を掘り集める。 |
| 承 | 石が増えるたびに口うるさい仲間が増え、石と女は喧嘩しながらも、互いがいないと何もできないと分かっていく。 |
| 転 | 繰り返しを守りたい上の者たちが、集めた石を奪いに来る。少年は彼らの側について、同じ力で立ちはだかる。 |
| 転 | 石を奪われ、仲間はばらばらになる。 |
| 結 | 石は仲間を信じて任せ、少年も自分で選び直し、衝突を逸らす。 |
| 結 | 帰った村に、また雪が積もる。 |

- **良いところ：** 発掘・収集のワクワクが、物語を動かすエンジンになる。仲間が増えて居場所ができる流れがはっきりする。
- **弱いところ：** 少年と一緒にいる時間が短く、「一歩引いて見守る」が弱くなる。女の使命が揺らぐ転換がない。

## 案C：村に帰る（小さく、濃く）

| | |
|---|---|
| 起 | 一番下の石は、次の衝突で自分が潰れると知る。でも、毎朝雪を払いに来る少年を、黙って見守っている。 |
| 起 | 女が石を盗むが、石が協力しないので女は捕まり、追放される。 |
| 承 | 石は初めて少年に頼み、少年は石を女に渡す。二人は底なしへ落ちる。 |
| 承 | 底の世界で、二人は追放された者たちと、かつて衝突を受けきれずに滅んだ村の石を見つける。 |
| 転 | 衝突を逸らす方法を持って村へ戻るが、村は二人を受け入れない。少年は掟に従って二人を阻む。 |
| 転 | 衝突の夜、石は自分を差し出そうとするが、少年に止められる。 |
| 結 | 石と女と少年と、追放された者たちが力を合わせて、衝突を逸らす。 |
| 結 | 石は積み直された石積みの中に戻り、村に雪が積もる。 |

- **良いところ：** 「一歩引いて見守る」と「帰る場所」（エンディングのイメージ、村八分からの逆転）が一番強い。一冊できれいに閉じる。
- **弱いところ：** 舞台が狭い。発掘・収集は底の世界の一回だけで、「仲間がどんどん増える」が弱い。

## AIのおすすめ

- **一冊目として書くなら、案C。** 最小プロットとして一番単純で、山奥屋の「単純化できなければ練りきれていない」に一番かなっている。
- **シリーズ全体の形としては、案A。** 案Cの「村に帰る」を一冊目にして、案Aの「村々を回る、迎えに行く」をその先に置く、という組み合わせもできる。
- どれを選んでも、言い回しはあなたの言葉で書き直してください。最小プロットは作者の才能が出る部分です。
