## 第一部の一行

動けない石が、消える日を待つだけの村から、信じていない女に運ばれて出ていく。出られたのは、黙って見守ってきた少年に、初めて「頼む」と言えたから。

## 太郎の変化（第一部ではここまで）

| 時点 | 太郎 |
|---|---|
| 始め | 誰にも気づかれずに雪を落とす。「どうせまた積もるのに」。誰も信じない（そもそも話せない） |
| 中ほど | 外に出たいのに、出してくれる花子を信じない。協力しない → 花子が捕まる |
| 終わり | **初めて頼む**（大志に）。花子の手で力を使うことを受け入れる |
| 取っておく | 「信じる」「報われたいと願う」「また積もるのに、とは思わない」は物語の最後まで |

ラスト（ビート10）でも太郎は「また積もるのに」と思う。ただ、その続きが少しだけ違う。

## ビート（10場面）

表の記号：**掘**＝発掘・収集／**見**＝一歩引いて青春を見守り、自分も成長する／**なく**＝お互いになくてはならない（構想メモの「すごくやりたい」3つ）。◎強い ○ある △におわせ程度 －なし

### 1. 暗闇で目覚める（短く）

- **誰が何を欲しがる：** 太郎：眠りたい（徹夜明けの続きのつもり）。ここがどこか知りたい
- **何が邪魔する：** 目を閉じられない。手足がない。真っ暗で、音がこもっている（雪の下）
- **場面の後で何が変わる：** 誰かが雪を払うと、光と音が戻り、ぼんやりしていた意識がはっきりする。太郎は「自分では何もできない」「雪に埋まると自分が薄れる」と知る。→ そして「それから◯年」と時間を飛ばす
- **この場面に必要な設定：** 雪に埋まると意識が薄れる（世界観次第。無しなら、ただの暗闇と退屈でもよい）
- **やりたい3つ：** 掘△（掘り出された直後の目覚め、とも読める。問5でA）／見－／なく－

### 2. 暇している石の朝（日常）

- **誰が何を欲しがる：** 老人：腰が痛いが、屋根の雪を今朝のうちに下ろしたい／大志：老人より先に雪かきを終えたい／太郎：静かに眠りたい
- **何が邪魔する：** 毎晩積もる雪。毎朝のお祈りがうるさい。太郎の声は誰にも届かない
- **場面の後で何が変わる：** 老人が石を握って祈ると、太郎がこっそり振動で屋根の雪を落とす。「石様のご利益じゃ」。太郎《どういたしまして》。大志は毎朝「今日も怖くないです」と言う。太郎《昨日もそう言ってた》。**読者が太郎の癖（どうせと言いつつやる、誰にも気づかれずに働く）と、三人の関係を知る**。太郎は雪を見て「どうせまた積もるのに」
- **この場面に必要な設定：** 石の力（振動で雪を落とす）。力を出すには誰かが触れている必要がある。太郎の声は届かない（いまのところ）
- **やりたい3つ：** 掘△（老人が「わしが若い頃に掘り出した」とこぼす。問5でA）／**見◎**（大志の毎朝の本音を、石だけが聞いている）／なく－

### 3. 衝突の日取り。太郎は自分が消えると知る

- **誰が何を欲しがる：** 村の長：誰も失わない村にしたい（そのために一人を差し出す）／大志：役目を果たして認められたい／太郎：消えたくない → **ここから出たい**
- **何が邪魔する：** 太郎は動けない。出れば大志の役目を奪う。大志は役目を誇りにしている
- **場面の後で何が変わる：** 長が次の衝突の日を告げ、大志が石と「結ぶ」修行を始める。長の言葉（または儀式の言い伝え）から、太郎は**衝突の日に受け手が石に入り、今の自分が上書きされる**と知る。**期限ができる。** 同時に、毎朝見てきた少年の役目と、自分が生き残ることがぶつかる
- **この場面に必要な設定：** 衝突の間隔と、次はいつか（村の時間の感じ方）。受け手は衝突を受けるとどうなるか（**世界観次第**。末尾の表）。村の長（**キャラ次第**。置かないなら大志の師匠か老人が兼ねる）
- **やりたい3つ：** 掘－／**見○**（見守ってきた少年の行く先が、自分の消滅とつながる）／なく－

### 4. 花子が石を盗む

- **誰が何を欲しがる：** 花子：石が欲しい（衝突を避けるため）／太郎：ここから出たい。でも、この女は信用できない
- **何が邪魔する：** 花子は説明しない。太郎を「これ」と呼ぶ。掟（石を村から出してはいけない）
- **場面の後で何が変わる：** 夜、花子が祭壇から石を握る。**初めて太郎の声が届く**（「……誰だお前」「しゃべった」「太郎だ」「石が名乗らないで」）。太郎は振動を鳴らせば村に知らせられた。**でも鳴らさない。**「どうせ俺は運ばれるだけだ」と言い訳しながら。これは大志への黙った裏切りでもある。**太郎は外に出る手段を得たが、相手を信じていない**
- **この場面に必要な設定：** 掟。花子に太郎の声が聞こえる理由（**世界観次第**：花子だけ／触れている人だけ）。花子がどこから来たか（「外から来た」だけで足りる）
- **やりたい3つ：** 掘△（花子にとって石は「探し当てた一つ目」）／見－／**なく○**（出会い。動けない石と、石を使える女）

### 5. 雪原を逃げる。花子の目的と代償

- **誰が何を欲しがる：** 花子：追手が来る前に山を越えたい／太郎：計画を知りたい。花子に力を使わせたくない
- **何が邪魔する：** 花子は「山を越える」としか言わない（「それは方角だ」）。花子が力を一度使うと、手が冷たくなる
- **場面の後で何が変わる：** 花子が夢でうなされ、前回の受け手の記憶のかけらをこぼす（「衝突は止められた」）。太郎は花子の目的が「衝突を避けること」だと知る。花子は「屋根の雪、あんたでしょ」と言う。**太郎が初めて、正しい相手に気づかれる**（居心地が悪い）。一方で、力の代償が花子の体温だと分かり、太郎は「使わない」と決める
- **この場面に必要な設定：** 力の代償（**世界観次第**。体温案）。花子が見る記憶の中身のかけら（前回の受け手が最後に見たもの。全部は出さない）
- **やりたい3つ：** 掘○（花子「石はこれだけじゃない」。ほかの石をにおわせる）／見△／**なく◎**（離れられない理由：太郎は運んでもらわないと動けず、花子は太郎がいないと力が出ない。そして代償がケンカの種になる）

### 6. 追手。太郎が協力しない → 花子が捕まる

- **誰が何を欲しがる：** 大志：石を取り返したい（役目を盗まれた）／花子：逃げ切りたい／太郎：花子をこれ以上冷やしたくない。あと、花子を信じていない
- **何が邪魔する：** 雪庇・崖・吹雪。追手の先頭が大志
- **場面の後で何が変わる：** 崖際で花子が「やって」と言う。**太郎は拒む**（問4でA）。花子は捕まり、石は大志の手に戻る。太郎には、**自分のせいだ**という自覚が残る。同じ場面で、大志が花子に「返せ。それは俺の役目だ」、花子が「役目っていうのは、死ぬことでしょ」
- **この場面に必要な設定：** 大志が石を扱えるか（正規の使い手として。**世界観次第**）
- **やりたい3つ：** 掘－／見○（大志の役目への執着を、太郎は誰よりよく知っている）／なく○（「なくてはならない」の裏返し：太郎が手を貸さないと、花子は何もできない）
- **ピクサーのルール：** 捕まるのは偶然ではなく太郎の選択の結果。トラブルに巻き込むのは許される側なので問題ない

### 7. 村に戻る。裁き

- **誰が何を欲しがる：** 長：掟を守り、村を守りたい／花子：大志に分からせたい／大志：役目を守りたい。花子の言葉を聞きたくない
- **何が邪魔する：** 花子の言い方が最悪。大志は疑うことを知らない
- **場面の後で何が変わる：** 花子は衝突の日まで閉じ込められる（扱いは掟次第）。花子が大志に「同じ顔でそう言った人を知ってる」。**大志に揺らぎの種がまかれる。** 太郎は元の祭壇に戻される。冒頭と同じ場所、同じ景色、また雪が積もる。でも今度は太郎の胸が落ち着かない
- **この場面に必要な設定：** 掟を破った人の扱い。外から来た人をどう見るか（村は閉じている）
- **やりたい3つ：** 掘－／**見○**（花子と大志、二人の若者がぶつかるのを、太郎は祭壇から見ている）／なく△（離れて初めて、花子がいないと何もできないと分かる）

### 8. 夜の祈り。太郎が初めて頼む

- **誰が何を欲しがる：** 大志：いつものように「怖くないです」と言いたい。でも今夜は言えない／**太郎：花子を出したい（初めて、自分の外のことを欲しがる）**
- **何が邪魔する：** 太郎は自分では何もできない。声が届くかどうか分からない。届いたとして、大志が信じるか。届けば、何年も黙って聞いていたことがばれる
- **場面の後で何が変わる：** 大志が石の前で、初めて違う本音をこぼす（「……外って、どんなですか」でも「怖いです」でもいい）。太郎は**初めて自分から声をかける**。「頼む」。大志「……全部、聞いてたんですか」「聞いてた」「なんで黙ってたんですか」「怖くないって毎朝言ってたから。そういうことにしておきたいんだろうと思った」。**太郎の変化の第一歩：自分ではできないことを、人に頼む**
- **この場面に必要な設定：** 太郎の声が大志に届く条件（**世界観次第**。触れている人に届く／強く願うと届く／石と結ぶ修行が進んだから届く）
- **やりたい3つ：** 掘－／**見◎**（何年も見守ってきた少年との関係がひっくり返る）／なく△
- **点検（救出が偶然でないか）：** 救出は、太郎が頼むという選択と、次のビートの大志の選択から生まれる。偶然には頼らない

### 9. 救出

- **誰が何を欲しがる：** 大志：役目と、花子の言葉と、太郎の頼み、のどれを取るか決めたい／花子：逃げたい／太郎：花子を出したい
- **何が邪魔する：** 掟。長。代償（力を使えば花子が冷える）
- **場面の後で何が変わる：** 大志が自分で選んで、石を花子に届ける（または閉じ込めた戸を開ける）。花子が「やって」と言い、**今度は太郎がやる**。代償を花子が払うのを受け入れる、という形で、太郎は花子を頼る。逃げる途中、老人が二人を見つけるが、声を上げない（「石様が行きたいなら、そうじゃろ」）。老人の選択はおまけでよい（**キャラ次第**）
- **この場面に必要な設定：** 力の代償（体温）。振動か熱でできること（雪を崩す、戸を外す、など）
- **やりたい3つ：** 掘－／見○（大志が初めて自分で選ぶのを見届ける）／**なく◎**（太郎の力は花子がいないと出ず、花子の逃亡は太郎がいないと成らない。初めて二人で一つのことをする）

### 10. 村の境。大志の約束

- **誰が何を欲しがる：** 大志：役目を取り戻したい（でも半分は外を見たい）／花子：先へ進みたい／太郎：……まだはっきりしない
- **何が邪魔する：** 掟は大志に「追え」と言う
- **場面の後で何が変わる：** 境で大志が言う。「借りは返した。次は取り返す」（問2でA）。花子と太郎は村を出る。雪が降り始める。太郎はまた「どうせまた積もるのに」と思う。けれど続けて、《明日の朝、爺さんの屋根は誰が落とすんだろうな》と思う。**変化はここまで。** 衝突の期限はまだ残っている（第二部へ）
- **この場面に必要な設定：** 衝突までの残りの時間（第二部の時計）
- **やりたい3つ：** 掘○（花子の次の目的地は「ほかの石」がある場所）／見○（大志はこの先、追う者として育っていく）／なく○（離れられない二人が、まだ仲は悪いまま歩き出す）

## 世界観次第で、ビートがどう変わるか

世界観担当の案がまだ無いので、選択肢ごとの影響だけ書く。

### 受け手は衝突を受けるとどうなる？（ビート3・10の「期限」）

| 選択肢 | 太郎の切迫した事情 | ビートの変化 |
|---|---|---|
| 石に取り込まれ、次の石の人格になる（マスター提案の案B） | 大志が入ってきて、太郎は上書きされる | このファイルのまま。大志が太郎の「行く先」になり、見守りが一番強くなる |
| 受け手が死ぬ | 太郎は消えない。切迫しない | ビート3を「衝突の力を受けると石の中身が焼ける（太郎が消える）」に変えるか、「目の前で大志が死ぬのを見るしかない」を切迫にする。後者だと太郎の欲しいものが「出たい」から「大志を死なせたくない」に変わり、花子の盗みに乗る理由がずれる |
| 生き残るが何かを失う | 太郎は消えない | 期限は「雪に埋まる（案B）」と「花子が見る記憶」だけで作る。切迫はやや弱い |

### 太郎の声は誰に届く？（ビート2・4・8）

| 選択肢 | ビートの変化 |
|---|---|
| 触れている人だけ（キャラ担当のおすすめ） | このファイルのまま。ただし老人と大志も毎朝触れているので、「なぜ今まで届かなかったか」に理由が要る（例：太郎が話しかけようとしなかった／石と「結ぶ」修行が進んで届くようになった）。**太郎が今まで話しかけなかった、が一番太郎らしい**（誰も信じていない） |
| 花子だけ | ビート8が成り立たない。太郎が頼む相手は花子になり（問3でB）、大志の選択は「花子の言葉」から生まれる形に変える |
| 誰とでも | 2の「誰にも気づかれず働く」が弱くなる。太郎が「黙っていることを選んでいた」にすれば成り立つ |

### 雪に埋まると意識が薄れる？（ビート1・2）

- ある → 老人と大志の雪かきが、知らないうちに太郎の命綱になる。雪のモチーフが生き死にとつながる
- ない → ビート1はただの退屈な暗闇。切迫は衝突の期限だけで作る（ビート3まで切迫が出ない）

## キャラ担当の案との関係

- 年齢（太郎38／花子23／大志16／老人70代）、小さい欲求（太郎・花子の「眠りたい」の対、大志の「老人より先に雪かき」）、掛け合いの例は、キャラ担当の案をそのまま使った
- キャラ担当の問4「大志は第一部の終わりでどうする？」のおすすめ「追う」と、このファイルの問2のおすすめは同じ方向（ただし「一度助けてから追う」を足した）
- キャラ担当の「第一部は『頼む』で止める」と同じ線にそろえた
- 村の長はキャラ担当のおすすめ（大志の育ての親で村の長）を仮に使った。置かない場合は、ビート3・7で大志の師匠か老人が兼ねる
