# 石の仕組みと世界観：3案

> AIのまとめ。作者「石の仕組みと世界観設定の方をシンプルに3案だして」（構想メモ 2026-11-18 末尾）。決めるのは作者。
> どの案でも変わらないこと：石の力は「傾ける（動かす・浮かべる・飛ぶ）」と「しまう・出す」／燃料が要る／中の人（太郎）は素人／電池の石（規格品）と、要の石（人が入った特別品）がある。

---

## 案A：重力の窓（一番シンプル）

| | |
|---|---|
| **選んだもの** | 空間（時空）を曲げる／電池の石と要の石／観測者が要る |
| **変えるところ** | 隣の世界（マルチバース）は出さない。石ができるのは**重力だけ** |
| **こんな感じになる** | 一言で言える：**「石は、重力を出し入れする窓」**。傾ける＝重力の向きを変える、しまう＝重力で折りたたんだ小部屋に入れる。力の幅は狭いが、バトルの理屈がわかりやすい |
| 太郎が特別な理由 | 要の石は、見ている心がいないと動かない。太郎はその心 |
| 応用力 | 中（重力だけなので、石ごとの違いは「強さ」と「範囲」くらい） |
| わかりやすさ | ◎ |

## 案B：常世の窓（広がる）

| | |
|---|---|
| **選んだもの** | ブレーン宇宙（隣の膜が近い）／石ごとにつながる世界が違う（真空のランドスケープ）／観測者が要る（向こうから来た心） |
| **変えるところ** | 太郎の石の力（傾ける・しまう）を、**「太郎の石は、重力が集まっている隣の膜（重力ブレーン）につながっている窓だから」**と説明する。ほかの石は、それぞれ別の決まりの世界につながっていて、別の力を持つ |
| **こんな感じになる** | 一言で言える：**「石は、隣の世界への窓。窓の向こうの決まりが、こちらで力になる」**。掘り出すたびに、まったく違う力の石が出てくる（ディメンションWの番号つきの装置のような作り方）。収集と発掘が一番楽しくなる |
| 太郎が特別な理由 | 窓を開けておけるのは、向こう側の世界から来た心だけ。太郎はその一人 |
| 応用力 | ◎ |
| わかりやすさ | ○ |

## 案C：記録の石（謎が深い）

| | |
|---|---|
| **選んだもの** | ホログラフィー原理（中の情報は、すべて表面に書き込める）／「空間は情報（量子のつながり）からできている」という現実の物理の考え（ER=EPRなど）／観測者の話（ウィグナーの友人） |
| **変えるところ** | 石を「窓」ではなく**「書き換える装置」**にする。石は、まわりの空間をつくっている情報を書き換えられる。しまう＝ものを情報にして石の表面に書き込む、出す＝組み直す、傾ける＝空間の情報を書き換えて重力を変える |
| **こんな感じになる** | 一言で言える：**「石は、世界を書き換える装置」**。太郎の心も、石の表面に書き込まれた情報だった（転生の理由が、理論にそのままつながる）。詳しい人ほど唸る。ただし説明が難しい |
| 太郎が特別な理由 | 石の表面に書き込まれた、人の心そのもの |
| 応用力 | ○（何でも書き換えられそうに見えるので、制約をはっきり決める必要がある） |
| わかりやすさ | △ |
