# 普通の石と、太郎の石の違い（世界観として）

> AIの提案。作者「そういう物語的なものじゃなくて世界観的に、古代文明は石がバッテリーっぽいけど、普通の石と太郎は何が違うのかなと」（構想メモ 2026-11-18 末尾）。決めるのは作者。
> 大きな嘘は一つだけ（「石は空間を曲げられる」）のまま、**同じ仕組みの使い方の違い**で分ける。

## 案：電池の石と、要（かなめ）の石

| | 普通の石（電池の石） | 太郎の石（要の石） |
|---|---|---|
| 中身 | 内側に、ごく小さく折りたたんだ空間がある。そこに**エネルギーだけ**を閉じ込めている | 内側の空間に加えて、**外の空間も曲げられる** |
| できること | ためる・出す（熱、動きのエネルギー）。遺物に差せば、遺物を動かす燃料になる | 傾けて動かす・浮かべる／ものをしまう／**ほかの石と遺物をつないで、まとめて動かす** |
| 数 | たくさんある。毎年の星降りで拾える「熾石（おきいし）」もこれ。村の暖房や灯りに使われている | 古代でも、ごくわずかしか作られなかった |
| 動かし方 | 決まった動きしかしないので、誰でも使える | 空間を曲げる向きと強さを、その場その場で決めなければならない。**決めるための「心」が要る** |
| 中に人は | いない | **人の心が入っている** |

### なぜ要の石には、人の心が要るのか

- 空間を曲げる計算は、古代の機械でも追いつかなかった（構想メモ：「コンピュータのスケーリング則、微細化は限界。何か新たな方法で計算リソースの獲得を目指す」）
- そこで古代の人は、**人の心（人格）を写して、石に入れた**。人の心を、計算の代わりにした（構想メモ：「石には人格が投影されている」「ソーディアン（人格のコピー）」）
- だから要の石には、必ず誰かの心が入っている。太郎は、その一人

### これで決まること

- **太郎の特別さ：** 世界にたくさんある「電池の石」の中で、数少ない「要の石」の一つ。しかも心が入っている
- **遺物の発掘：** 遺物は、電池の石を差せば動く。でも、**大きな遺物（船など）をまとめて動かすには、要の石が要る**。だから太郎がいると、掘った遺物が本当の力を出す
- **ライバル：** もう一つの要の石。中にも、写された心が入っている
- **「転生」の正体（奥の謎の候補）：** 太郎は、生まれ変わったのではなく、心を写された（コピーされた）のかもしれない。本人の本物の人生は、どこかで普通に続いて、終わっていたのかもしれない（構想メモの「ウトウトしてから死ぬまでの人生を忘れているのか、夢なのか、はまだ決めない」とつながる）
- **なぜ現代人の心なのか：** 奥の謎として残す

### 気をつけること
- 「人の心を写して道具に入れる」は、少しぞっとする話。前に出しすぎない。表は明るく、奥の謎として少しずつ
- 作者が最初の構想メモで書いていた考え（人格のコピー、計算資源、石に人格が投影される）から組み立てているので、新しい設定は足していない
