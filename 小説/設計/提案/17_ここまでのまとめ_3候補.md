# ここまでのまとめ：3つの候補

> AIのまとめ。作者「ここまでの話をシンプルな３つくらいの候補にまとめたい。候補はそれぞれこれとこれとこれを選定して、そこからこういうところを変えて、このかんじにする。」（構想メモ 2026-11-18 末尾）。決めるのは作者。

## 3候補に共通する土台（決定ログで決まっていること）

- 現代の会社員が、雪国の村の御神体の**丸い石**に転生する。語りは石の目。会社員だと自覚している
- 世界の嘘：**すぐ隣に、別の決まりで動く世界（常世）が重なっている。石はそこへの窓。** 窓は、向こうから来た心が見ているあいだだけ開く（だから石に人が入っている）
- 石の力：傾ける（動かす・浮かべる・飛ぶ）／しまう・出す。制約は燃料と、中の人が素人。切り札あり。成長は使いこなすこと
- 東北の冬の村。排他的だが、中に入れば親切。巨大な人型の機械は出さない

## 候補1：船と遺物の冒険（∀型）

| | |
|---|---|
| **選んだもの** | 最小プロット第10版（∀の形）＋石ごとにつながる世界が違う（掘るたびに違う力）＋船 |
| **変えるところ** | 「石は星を落とした道具だった」をやめて、**「石は昔、窓を開けすぎて別の世界の決まりを流れ込ませ、文明を終わらせた道具だった。この世界の長い冬は、そのときの名残」**にする（星は膜の話と関係させない、の決定に合わせる） |
| **こんな感じになる** | 空の上から来たよそ者の娘と石が、雪に埋もれた船を掘り当てて、遺物を集めながら世界を回る。上の人々と地上の人々の争いをつなぎ、同じ時代のもう一つの石（ライバルの転生者）と戦う。壮大で、シリーズ向き |
| 一番の楽しさ | 船、遺物の発掘、仲間が増える、同じ力どうしの戦い |
| 難易度 | 高い（人物も舞台も多い） |

## 候補2：村の守り神（web小説型）

| | |
|---|---|
| **選んだもの** | 最小プロット第8版（村の守り神に転生したが、守り方がわからない）＋web小説素案（章ごとに困りごとを片づける）＋転生もののお約束（実はすごい、ステップアップ） |
| **変えるところ** | 大きな困難を「星」から**「窓のほころび」**に変える。窓の向こうの決まりが村に漏れて、重さが変わる日、季節外れの吹雪、時間がずれる沢、といった困りごとが起きる。章ごとに一つ片づけ、近くの遺跡で別の窓石を掘り出していく |
| **こんな感じになる** | 見習いの少年と石のバディが、村の困りごとを毎章スカッと片づけ、よそ者の娘も村に受け入れられていく。拠点は村。明るくてテンポがよく、1巻ごとに区切れる |
| 一番の楽しさ | 実はすごい石、章ごとのスカッと、居場所ができる |
| 難易度 | 低い（舞台が村中心、型が決まっている） |

## 候補3：石たちの証言（謎解き型）

| | |
|---|---|
| **選んだもの** | 人格の入った石の証言集め（『誰が勇者を殺したか』型）＋観測者の話（ウィグナーの友人）＋要石の言い伝え |
| **変えるところ** | 敵との戦いを中心にしない。中心の謎を一つ宣言する：**「この村を冬にしたのは誰か」**（または「前に、この石に入っていたのは誰か」）。掘り出した石の中の人たちは、それぞれ違う証言をする。**窓の向こうで何が起きたかは、見ていた者にとってだけ本当**なので、証言どうしが食い違っても、全員が嘘をついていない |
| **こんな感じになる** | 石と少年が、村のまわりに眠る石を掘り出しては話を聞き、食い違う証言から真相を組み立てる。考察が楽しく、静かで、少しぞっとする。最後に「誰から見た真実か」がひっくり返る |
| 一番の楽しさ | 謎、考察、発掘（掘る＝証人が増える） |
| 難易度 | 中くらい（謎の組み立てに手間がかかる） |
