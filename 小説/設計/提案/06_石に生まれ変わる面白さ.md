# 石に生まれ変わって、何が面白いのか

> AIの壁打ち。作者の問い「石に生まれ変わってなにが面白いのだろう」（2026-11-18 チャット）への答えの案。決めるのは作者。

## 結論

石であること自体は面白くない。人以外のもの（剣、自販機、蜘蛛など）に生まれ変わる話は、もう一つのジャンルになっている。
面白くなるのは、**石であることが、この主人公の弱点をまっすぐ突くとき**。

太郎は「できる人がやるしかない」と全部自分で抱え、他人を信じない人。
そんな人が、**自分では一歩も動けない**ものになる。誰かに握られ、運ばれ、頼まないと何もできない。
石になること自体が、太郎の試練になっていて、変わっていく道筋にもなっている。

## 石だからこそ生まれるもの（今の案の中で）

| 面白さ | 中身 | つながる「やりたい」 |
|---|---|---|
| **頼るしかない** | 自分で何でもやってきた男が、何もできない。頼むこと自体が大事件になる | 太郎の変化 |
| **道具あつかいのおかしさ** | 「これ」と呼ばれる、ポケットに突っ込まれる、投げ渡される、ご利益だと拝まれる。中身は38歳の会社員で、心の中でずっとツッコんでいる | バディの掛け合い・ツッコミ |
| **時間の長さ** | 石は動かずに何年も見ている。少年が毎朝お祈りに来るのを、ずっと黙って聞いてきた。人は育って去っていくが、石は残る | **一歩引いて青春を見守る（すごくやりたい）** |
| **片方だけでは何もできない** | 石は人がいないと動けない。人は石がいないと力が使えない | **お互いになくてはならない（すごくやりたい）** |
| **自分がお宝** | 主人公は掘り出される側。仲間を増やすのは、自分と同じ石を掘り出すこと。集めるものが、しゃべって文句を言う | **発掘・収集（すごくやりたい）** |
| **眠れない** | 徹夜明けのまま、まぶたがないので眠れない。代償の「眠り」と対になる | 笑いと、最後の着地 |
| **積まれる** | 雪が積もるように、石も積まれる。「どうせまたつもる」側にいるのが自分 | テーマ（言わずに伝える） |

## 点検の方法

**「その場面は、主人公が石でなくても成り立つか？」** と聞いてみる。成り立つなら、石の面白さを使えていない。
- 成り立たない（良い）：毎朝のお祈りを黙って聞く／盗まれる／協力したくなくて重くなる／少年に投げ渡される／落ちても割れない／眠れない
- 成り立ってしまう（要注意）：第二幕の「戦う」「旅をする」部分。ここで石らしさが消えると、ただの異能バトルになる

## 弱いところ

- **主人公が受け身になりやすい。** 動けないので、話を動かすのはいつも他人になる。だから「頼む」「手を貸さない」「重くなる」といった、**石にできる選択**を毎回はっきり置く必要がある
- 一人称で書くと、景色が「握られた手の中」ばかりになりがち。見えるもの・聞こえるものの範囲を、早めに決めておくとよい（中プロットの段階で）

- 6行目「自分ひとりを差し出そうとする」→ 動けない石が自分を差し出すには、誰かに運んでもらうしかない。**誰に頼んで運ばせるのか**が、どん底の苦さになる
