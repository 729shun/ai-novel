# ブレーン宇宙から、設定の種

> AIの発散。作者「ウィークブレーン、重力ブレーンとか、余剰次元とか、バルクとかマルチユニバースとかで応用力がある面白い設定の種ないかな？」（構想メモ 2026-11-18 末尾）。決めるのは作者。
> 「現実の物理（仮説を含む）」と「作品の嘘」を分けて書く。物理の中身はAIの知識による。

## 現実の物理（仮説）のおさらい

| 考え | 中身 |
|---|---|
| ブレーン（膜）とバルク | この宇宙は、もっと次元の多い空間（**バルク**）に浮かぶ、一枚の**膜（ブレーン）**かもしれない。光も物質も膜に張りついて離れられないが、**重力だけは膜の外（バルク）にも漏れる** |
| 重力ブレーンと弱いブレーン（ランドール＝サンドラム模型） | バルクの中に膜が二枚ある。重力は片方の膜（**重力ブレーン**）に集まっていて、もう片方の膜（**弱いブレーン**）では重力が薄い。私たちは弱いブレーンにいるので、重力がほかの力よりずっと弱い |
| 大きな余剰次元（ADD模型） | 重力が弱いのは、広い余剰次元に薄まっているから |
| 膜どうしの衝突（エキピロティック宇宙・サイクリック宇宙） | 二枚の膜が近づいてぶつかったのがビッグバンだった。ぶつかっては離れ、を**何度も繰り返している**のかもしれない |
| 隣の膜の物質（影の物質） | 見えないのに重さだけがある暗黒物質は、すぐ隣の膜にある物質かもしれない。重力しか届かないので、見えない |
| ホログラフィー原理 | ある空間の中の情報は、すべてその**表面**に書き込めるかもしれない（構想メモにもある） |
| マルチバース | 膜は無数にあり、それぞれが別の宇宙で、物理の決まりも少しずつ違うかもしれない |

## 種（応用力がありそうなもの）

### 種1：隣の膜には、もう一つの地球がある
- **嘘：** バルクのすぐ隣に、別の膜がある。そこにも地球がある。**それが太郎のいた現代日本**
- 二つの膜は、重力でしかつながっていない。**石は、重力の通り道（口）**
- **太郎の転生の正体：** 太郎は、過去から来たのでも、未来から来たのでもない。**隣の膜の地球から、重力の通り道を抜けて、心だけが来た**
- **応用：** 古代文字が読める、ではなく「なぜか自分の世界の物がそっくり埋まっている」。隣の膜とこちらの膜は、昔、何かを行き来させていた？

### 種2：石ごとに、つながっている先の宇宙が違う（マルチバース）
- **嘘：** 要の石の口は、それぞれ**違う膜（違う宇宙）**につながっている。その宇宙の物理の決まりが、石の力になる
  - 重力の強い宇宙につながる石 → 重さを操る
  - 時間の流れが速い宇宙につながる石 → しまったものが一瞬で何年も経つ（熟成、成長、風化）
  - 熱い宇宙につながる石 → 熱をいくらでも出す
- **応用力が一番高い：** 掘り出す石ごとに、まったく違う力になる。それでいて理屈は一つ（「つながる先の宇宙の決まり」）。『ディメンション W』の番号つきの装置にあたる作り方
- **太郎の石：** 太郎のいた宇宙（隣の膜の地球）につながっている。だから太郎の心が入った
- **ライバルの石：** 別の宇宙につながっている。中の転生者も、太郎とは別の地球から来た人かもしれない

### 種3：膜が近づく周期が、大きな星を呼ぶ（エキピロティックの小さい版）
- **嘘：** こちらの膜と隣の膜は、ゆっくり揺れていて、**数百年に一度、近づく**。近づくと重力が強まり、空の帯（輪）のかけらが落ちてくる。それが「大きな星」
- 本当にぶつかったら、両方の世界が終わる（新しいビッグバンになる）
- **古代の人が石を作った理由：** 膜と膜の間の**つっかえ棒**として。石が重力の通り道を開け閉めして、二枚の膜が近づきすぎないようにしていた
- **民話とつながる：** 日本には、地面の下の大鯰（地震）を押さえている「**要石（かなめいし）**」の言い伝えがある（鹿島神宮など）。**村の御神体＝要石。押さえていたのは、鯰ではなく、隣の世界**
- **応用：** 「繰り返し」が、宇宙の規模の繰り返しになる。「失敗の繰り返し」は、前の近づきのときに、つっかえ棒がうまくいかなかったこと

### 種4：上の人々は「空の上」ではなく「膜の上」にいる
- **嘘：** 「上」とは、空ではなく、**バルクの方向**。上の人々は、重力ブレーンに近い側に住んでいる（そこでは重力が強い）
- **応用：** 物語の途中で「上」の意味がひっくり返る。ただし抽象的なので、絵にしにくい（使うなら奥の奥の謎）

### 種5：心は、石の表面に書き込まれている（ホログラフィー）
- **嘘：** 心（人格）は情報。情報は、空間の表面に書き込める。要の石の表面には、中に入った人の心が、ホログラフィーのように書き込まれている
- **応用：** 石が欠けると、記憶が欠ける。かけらを戻すと、記憶が戻る（「かけら」の線とつながる）

### 種6：見えない重さ（影の物質）
- **嘘：** 隣の膜の山や建物は、こちらからは見えないが、**重さだけは感じる**。雪がある場所だけ、なぜか積もらない（そこに隣の世界の家がある）
- **応用：** 雪国の怪談・民話として出せる（「雪が積もらない場所には、見えない家がある」）。東北の冬の不思議と、SFが一致する

## 組み合わせのおすすめ

**種1＋種2＋種3（＋種6を小道具に）**

- **世界の嘘：** 宇宙は、バルクに浮かぶ無数の膜の一枚。要の石は、別の膜への重力の通り道
- **太郎：** 隣の膜の地球（現代日本）から、通り道を抜けて心だけが来た。だから太郎の石は、太郎の世界につながっている
- **石ごとの力：** つながる先の宇宙の決まりで決まる（掘るたびに違う力）
- **大きな星：** 数百年に一度、隣の膜が近づくせいで落ちてくる
- **御神体＝要石：** 二枚の膜が近づきすぎないように押さえる、つっかえ棒
- **民話の手ざわり：** 「雪が積もらない場所には、見えない家がある」

これで「なんで石か」「なんで現代人か」「なんで星が落ちるか」「なんで石ごとに力が違うか」「なんで繰り返すのか」が、**一つの嘘（膜とバルク）**から出てくる。
