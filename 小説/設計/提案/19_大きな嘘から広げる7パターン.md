# 大きな嘘から広げる：7パターン

> AIの発散。作者「石の力とかを固定せずに、さっきまで会話していたSFチックな理論と、ディメンションWてきな、嘘とそこから考えられる設定の展開や物語の展開を何パターンか様々考えてほしい」（構想メモ 2026-11-18 末尾）。決めるのは作者。
> 作り方（ディメンションWから借りたもの）：**嘘を一つだけ置き、物理の言葉で言えるようにする → その嘘から、暮らし・社会・規格品と規格外品まで決める → 特別なものも同じ理屈の延長にする。**
> 石の力は固定しない。嘘ごとに、石が何になるかも変わる。物理の中身はAIの知識による。

## 1. 重さは汲み出せる（重力の井戸）

| | |
|---|---|
| **嘘** | 隣には、重力が集まった世界（重力ブレーン）がある。石はそこへ掘った**井戸**。重さを汲み出したり、流し込んだりできる |
| 現実の下敷き | ランドール＝サンドラム模型（重力は別の膜に集まっていて、こちらでは薄い） |
| 設定の展開 | 重さが**資源**になる。重さを汲み出した土地は**空に浮く**（空に浮かぶ村、上の人々の島）。重さを売り買いする商人、重さ泥棒。汲みすぎた土地では雪が上に向かって降る。電池の石＝重さを詰めた樽 |
| 物語の展開 | 空の島は、井戸の石が古びて少しずつ沈んでいる（上の人々が地上に降りたい理由）。地上の村の御神体は、島を浮かせている井戸の**栓**だった。栓を抜けば島は浮き続けるが、村が潰れる |
| 石と太郎 | 栓の石。井戸の水位を見張る番人として、心が入っている |
| 一番の楽しさ | 絵が明るい（浮島、上へ降る雪、重さの商売）／∀やGレコの明るさ |

## 2. 見た者の世界だけが決まる（ウィグナーの友人）

| | |
|---|---|
| **嘘** | 起きたことは、**見た者にとってだけ確定する**。石は、ある範囲を「見続ける」ための見張り台 |
| 現実の下敷き | ウィグナーの友人、関係解釈（結果は、誰から見た結果かで決まる） |
| 設定の展開 | 村ごとに見張りの石があり、村の中の出来事を確定させている。隣の村とは、少しだけ歴史や天気が食い違う。**誰も見ていない村の外は、まだ決まっていない**（地図にない土地＝まだ確定していない土地）。旅をすると、行った先が「確定」していく |
| 物語の展開 | 外を旅するほど世界が決まっていく（探検そのものに意味がある）。もう一つの見張りの石が、同じ土地を**違う形**で確定させようとしてぶつかる。文明が途切れたのは、見張りどうしの食い違いが大きくなりすぎたから |
| 石と太郎 | 見張り台。太郎は**別の世界から来た目**なので、この世界の誰とも違う見え方で確定させてしまう |
| 一番の楽しさ | 考察（「確定していない」の意味）／探検に意味がある |

## 3. 時間はしまっておける（時間の蔵）

| | |
|---|---|
| **嘘** | 石の中の折りたたまれた空間では、時間の流れを好きに変えられる。**時間を、ためたり、しまったりできる** |
| 現実の下敷き | 重力による時間の遅れ（強く曲がった時空では時間がゆっくり進む） |
| 設定の展開 | 村は、**冬の一部を石にしまって**短くして越えてきた（でも、しまった冬はいつか出さなければならない）。保存食・酒・漬物の熟成に使う（東北の暮らし）。病人を時間の止まった部屋に入れて、治せる人が来るのを待つ。時間のずれた沢、年をとらない子 |
| 物語の展開 | 何百年分しまい込んだ冬が、石のひびから漏れ始める（この世界の長い冬の正体）。村は**同じ冬を、しまっては出して、文字どおり繰り返していた** |
| 石と太郎 | 時間の蔵。太郎自身も、蔵の中で何千年もしまわれていたのかもしれない（浦島太郎） |
| 一番の楽しさ | 「繰り返し」がそのまま世界の仕組みになる／東北の冬の暮らし |

## 4. この世界は、隣の世界の影（ホログラフィー）

| | |
|---|---|
| **嘘** | この世界は、隣にある**本当の世界の表面に映った影**。石は、影と本体をつなぐ穴 |
| 現実の下敷き | ホログラフィー原理（中の出来事は、すべて表面の情報として書ける） |
| 設定の展開 | 影の世界では、物理の決まりが少し単純になっている（だから、魔法のようなことが起きやすい）。石の穴を通すと、本体の側の力を少しだけ引き出せる |
| 物語の展開 | どちらが影で、どちらが本体なのか。**太郎のいた現代の地球のほうが影だった**、というひっくり返しもありうる |
| 石と太郎 | 穴。太郎の心は、もう片方の側から映り込んだもの |
| 一番の楽しさ | 最大級のどんでん返し。ただし抽象的で、絵にしにくい |

## 5. 選ばれなかった世界が、すぐ隣に並んでいる（多世界）

| | |
|---|---|
| **嘘** | 量子の枝分かれでできた別の世界は、ほんの少しだけ重なったまま、すぐ隣に並んでいる。石は、**枝分かれの点**。世界を「選び直す」ことができる |
| 現実の下敷き | 多世界解釈（すべての結果が、それぞれ別の世界として起きている） |
| 設定の展開 | 古代の人は、失敗するたびに石で世界を選び直してきた。何度もやり直した結果、世界がゆがんだ（冬、曇り空、ずれた土地）。石の中には「選ばれなかった世界」がしまわれている |
| 物語の展開 | 太郎は、**文明が途切れなかった枝の地球**（現代日本）から来た。ライバルも、また別の枝から来た。最後に「選び直す（やり直す）」ことをやめ、**一度きりの今を選ぶ** |
| 石と太郎 | 枝分かれの点。太郎は、隣の枝の人 |
| 一番の楽しさ | テーマと一番まっすぐ重なる（繰り返し＝やり直しをやめる → 「またつもるのに、とは思わない」） |

## 6. どんなものの中にも、畳まれた部屋がある（巻かれた次元）

| | |
|---|---|
| **嘘** | どんな物の中にも、目に見えないほど小さく巻かれた次元がある。古代の人は、それを**広げる**方法を知っていた |
| 現実の下敷き | 余剰次元（小さく巻き上がった次元があるかもしれない） |
| 設定の展開 | 古代の遺跡は、**小石の中に畳まれている**。船も、町も、工場も、小石ほどの大きさに畳まれて、雪の下に眠っている。広げるには燃料と鍵（要の石）が要る。畳んだ中は時間が止まっている |
| 物語の展開 | 発掘が「小石を拾う」になる。**拾った小石を広げたら、船が出てきた**（船を手に入れる、新しい遺物を掘る、が一番派手にできる）。畳まれた町の中に、古代の人が時間の止まったまま眠っていた |
| 石と太郎 | 畳まれたものを広げる鍵。太郎の石の中にも、何かが畳まれている |
| 一番の楽しさ | 発掘・収集・船・新しい遺物のワクワクが最大 |

## 7. 隣の世界とは、重力の波でしか話せない（重力の便り）

| | |
|---|---|
| **嘘** | 隣の世界とは、**重力の揺れ**でしかやりとりできない。石は、重力の揺れを出したり聞いたりする受話器 |
| 現実の下敷き | 膜の外に出られるのは重力だけ／重力波 |
| 設定の展開 | 村の鐘のような共鳴（構想メモ）、地鳴り、雪崩が、隣の世界からの「便り」。村には、揺れを読む役目の人がいる |
| 物語の展開 | 誰かが、隣の世界からずっと呼びかけている。太郎だけが、それを言葉として聞ける |
| 石と太郎 | 受話器。太郎は、呼びかけの「宛先」だったのかもしれない |
| 一番の楽しさ | 静かな謎、民話の手ざわり。規模は小さい |

## 組み合わせの例

- **6＋3：** 小石の中に、時間の止まった船や町が畳まれている。広げると、時間がまた動き出す。発掘のワクワク（6）と、繰り返す冬（3）が一緒に出る
- **6＋5：** 畳まれているのは、選ばれなかった世界のかけら。広げるたびに、別の枝の物が出てくる（太郎の世界の物も）
- **1＋6：** 重さを汲み出して浮かせた空の島と、小石から広げる船。一番明るく派手

**AIのおすすめ：** 表の嘘は**6（畳まれた部屋）**。一言で言えて、発掘・船・新しい遺物がそのまま派手になる。奥の謎に**5（選ばれなかった世界）**を置くと、テーマ（繰り返しをやめる）までつながる。
