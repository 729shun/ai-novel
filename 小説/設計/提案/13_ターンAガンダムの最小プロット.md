# ∀ガンダムの最小プロット（山奥屋の練習）

> AIが書いた例。作者の依頼「ターンエーの最小プロット出してみて」。
> **中身はAIの記憶による。細部に間違いがありうる。**
> 山奥屋の書き方に合わせて、名前は使わず「何が起きるのか」だけを書いた。

## 最小プロット

| 幕 | 行 | |
|---|---|---|
| 起 | 1 | 月で暮らす少年が、地球へ帰る下調べのために地上へ降り、田舎の名家で働きながら、地球の暮らしになじんでいく。 |
| | 2 | 成人の儀式の夜、村の神像の中から古代の機械が現れる。月の軍が攻めてくる中、少年はそれに乗って戦うはめになる。**【第一転換点】** |
| 承 | 3 | 少年は月と地球の両方を知る者として、戦いを止めようと走り回る。 |
| | 4 | 月の女王と地上の娘がそっくりだったことから二人は入れ替わり、それぞれの側から和平を探る。**【中間点】** |
| 転 | 5 | 古代の機械は、かつて地球の文明を丸ごと埋もれさせた兵器だったと分かる。 |
| | 6 | 戦いを望む月の一派が、同じ時代の兵器を掘り起こし、世界はふたたび文明が埋もれる危機に陥る。**【どん底】** |
| 結 | 7 | 少年は古代の機械で、同じ力を持つ敵と戦う。二つの機械は繭に包まれて眠る。**【山場】** |
| | 8 | 戦いは終わり、女王は地上で静かに暮らし、少年はそのそばで彼女を見守る。 |

## この作品の「驚きだが辻褄が合う」の作り方（AIの読み）

- **儀式で祀られていた像の正体が、文明を滅ぼした兵器だった。** 驚きのもとは、すでに置いてあった「神像」「儀式」「古代」がひっくり返ること。新しい設定を後から足していない
- **主人公は、よそ者。** 地上の村に、月から来た少年が入って受け入れられる（作者の「排他的な村人が、中に入れば親切」と同じ形）
- **遺物は、日常にも使われる。** 戦うだけでなく、暮らしの中で働く（明るさのもと）
- **同じ力どうしの戦い**で終わり、最後は**静かな暮らし**に戻る（作者のエンディングのイメージ「日々の暮らしのなかの戦いや冒険、帰る場所がある」と近い）
