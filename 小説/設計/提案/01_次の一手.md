# 次の一手（小プロット2を受けて）

> AIのコメント。本人の構想は `小説/構想メモ/2026-11-17.md`。

## 結論

次は**設定を足すのではなく、第一部（花子と太郎が村を出るまで）を「登場人物が欲しがるもの」で組み直す**。

1. 主要人物4人の「欲しいもの」を1行ずつ決める（下の「決めてほしいこと」）
2. 第一部を10場面くらいのビートに分ける。各場面には「誰が何を欲しがるか／何が邪魔するか／場面の後で何が変わるか」と、**その場面に必要な設定だけ**を書く
3. 冒頭の1場面（石として目覚めて、暇している太郎）を試しに書いてみる

---

## 小プロット2で良くなったところ

- **敵が「繰り返し・停滞」ひとつになった。** 世界（衝突が周期的に来る）、村（受け止め役を育てて受け継ぐ）、太郎（徹夜を繰り返す会社員）、花子（前回の受け手の無念を何度も見る）が、同じテーマの別の顔になっている。テーマを台詞で言わせずに伝える土台ができた。
- **設定が大きく減った。** 軌道エレベーター・火星・AI宗教が表から消えて、「衝突」「石」「村」「受け止め役」だけで物語が回る。ワールドビルダー病への対策として正しい方向。
- **「太郎はまたつもるのに。とは思わない。」は、太郎の変化のゴールだと読んだ。** 冒頭で雪を見て「また積もるのに」と冷めていた太郎が、最後に同じ景色を見ても、もうそうは思わない。エンディングの雪かきの詩とそのままつながる。テーマを言わずに伝える仕掛けとして一番強い。（読み違いなら教えてください）

## 足りないもの（次に決めること）

### 1. 太郎は何を欲しがっているか ← 一番大きな穴

今の太郎は「暇している」だけで、欲しいものがない。「水一杯でもいい」に照らすと、ここが最優先。

- **小さい欲求（水一杯）の案：眠りたい。** 徹夜明けなのに、石にはまぶたがなくて目を閉じられない。毎朝、村人がお祈りに来てうるさい。冒頭から欲求と笑いが同時に出せる。
- **大きい欲求の案：自分がやったことが報われてほしい。** 直しても直してもバグが湧く仕事、終わらない改修。「どうせまた積もる」は、本当は報われたい人の諦め。
- **ゴール：** 報われるからではなく、やってみたいから雪をかく。

### 2. 花子と太郎が「お互いになくてはならない」仕組み

仲が悪いバディを成り立たせるには、**離れられない仕組み上の理由**が要る。感情だけだと、ケンカしたら別れて終わってしまう。

- 石は自分では動けず、使い手がいないと力を出せない（**太郎には花子が必要**）
- 花子は村の訓練を受けた正式な使い手ではない。普通は村の作法で石を動かすが、太郎は現代人なので作法を知らない。だから花子とは「交渉」で動く（**花子には太郎が必要**）
- 力の代償（メモにある「体温」）を払うのは花子。力を使うたびに、太郎は花子が冷えていくのを感じる。だから太郎は力を使いたがらない → ケンカの種になる

こうすると、モメる理由が性格の相性ではなく仕組みから出てくる。掛け合いやツッコミのネタも尽きにくい。

### 3. 大志は何を欲しがっているか

大志は「繰り返す側」を代表する人物なので、悪役にしないほうがいい。

- **欲しいもの案：** 役目を果たして村に認められたい。前の受け手（父や師匠？）に恥じない自分でいたい。
- 花子が石を盗むのは、大志の**人生の意味を盗む**ことになる。大志から見た花子は「自分の人生を壊しに来た女」。
- 太郎は祀られている間、大志の毎朝のお祈りや修行を**石なので見ているしかなかった**。太郎は花子より先に大志を知っている。→「一歩引いた位置で青春を見守る（すごくやりたい）」と直接つながる。
- 後で「同じ力を持つ者どうしの戦い」の相手になり、さらにその後は仲間になる候補。

### 4. 「花子は村人に捕まってしまうが、、、」の続き（ピクサーのルール）

ここが第一部の山場。**偶然で助けない。** 助けは誰かの選択から出てこないといけない。

おすすめの流れ：

- **花子が捕まるのは、太郎が協力しなかったせい**にする（トラブルに巻き込む偶然はOK。でも太郎の非協力が原因なら、さらに良い）
- **太郎が初めて、自分の意思で力を使う。** それまでずっと暇していた石が、初めて自分で選ぶ。これが太郎の変化の第一歩になる。ただし代償は花子の体温なので、助けることがそのまま花子を傷つけることにもなる。
- **大志にも選ばせる。** 逃がす側になるか、追う側に回るか。大志も石とつながれる人なので、花子が見ている「前回の無念」の記憶を少し見てしまい、心が揺らぐ、というのも手。

### 5. 小プロット2で消えたもの：発掘・収集のワクワク（すごくやりたい）

小プロット2では、発掘は背景（石が発掘されて祀られる）にとどまっていて、物語を動かすエンジンになっていない。

**提案：** 小プロット2にもう「村は各所にある」と書いてある。それなら**どの村にも石があり**、花子の目的が「衝突を避けるには石がいくつも要る」だとすると：

| 仕組み | 実現できる「やりたい」 |
|---|---|
| 石を集める旅 | 発掘・レア物・収集のワクワク |
| どの石にも過去の人の人格が焼き付いている（ソーディアン） | 石を集める＝太郎の同類が増える、仲間が増える、居場所ができる |
| どの村にも受け止め役がいる | 同じ力を持つ者どうしの戦い |
| どの村も閉じている（江戸時代のよう） | 閉じた境界から出ていく話が、村ごとに繰り返せる |
| 石は凍土・ガラスの砂漠・竪穴に埋まっている | 発掘・オーパーツ・接着剤メモの場所がそのまま使える |

「すごくやりたい」3つと、ほかのやりたいことのいくつかが、ひとつのエンジンに乗る。第一部では全部を見せなくていい。花子の台詞か記憶で「ほかの石」をにおわせるだけで十分。

## 第一部に必要な設定だけ（ワールドビルダー病への対策）

**第一部の場面に必要なのはこれだけ：**

- 衝突はどのくらいの間隔で来て、次はいつか（「次の衝突まであと◯年」が村の時間の感じ方になる）
- **受け止め役は衝突を受け止めるとどうなるのか** ← 大志の運命の重さがここで決まるので、第一部で必須
- 村の掟（村から出てはいけない、石を守る）と、破った人がどうなるか
- 石が力を出す条件と、その代償
- 花子が見る記憶の中身（前回の受け手が最後に何を見たか、そのかけら）

**今は決めなくていいもの（倉庫に置いておく）：** 軌道エレベーター、火星、AI、砂、地軸、ホログラフィック原理、テクタイトの物理、太郎の転生の理由（夢なのか、死んだあとなのか）。場面が必要としたときに倉庫から出せばいい。

## 決めてほしいこと

1. **受け止め役は衝突を受け止めたらどうなる？**
   - 案A：死ぬ
   - 案B：**石に取り込まれる（次の石の人格になる）** ← おすすめ
   - 案C：生き残る（でも何かを失う）

   案Bにすると「石には人格が投影されている」という設定と受け手の運命がひとつにつながる。大志はいずれ**太郎のような存在になる**運命なので、太郎は大志の行く先そのものになる。太郎が見守る理由もずっと強くなる。
   さらに：前回の受け手の人格は、なぜか石に入らずに花子の側に漏れてしまった（だから花子は記憶が見える）。石が空っぽだったので、そこに太郎が入った――と考えると、「隠された秘密」の芯にもなる。（あくまで仮説）

2. **太郎は何年祀られていた？** その間に大志がどのくらい育つのを見ていた？（何年も見ていたなら、お話は「目覚め」からではなく「何年も暇している石」から始められる）
3. **大志は何歳？** 花子23歳、太郎（会社員なので30〜40代？）。太郎が二人を「見守る」年齢差になっているか。
4. **第一部はどこで終わる？** 村を出た瞬間か／大志が追ってくるところか／大志がついてくるところか。
